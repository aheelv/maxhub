会议记录、经营数据与指标全部为**课堂虚构数据**，不含真实单位、人员与财务信息。

| 文件 | 用途 |
| --- | --- |
| 01_会议原始记录.txt | 含跑题、重复、模糊表述的口语化记录 |

| 04_报告模板.md | 报告章节结构 |
| 05_PPT大纲模板.md | 10 页演示文稿结构 |
| 06_核对题.csv | 12 道跨产物数字核对题 |
| 07_提示词库.md | 7 类可复制提示词 |
| 08_验收量表.csv | 100 分量规机器可读版 |

核心纪律：所有数值必须来自 02_指标结果.json；四份产物不得各自重新口算。
