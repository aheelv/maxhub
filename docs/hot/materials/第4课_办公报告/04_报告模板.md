# 经营分析报告模板（章节结构，必填字段不得删减）

1. 报告基本信息：课程名、课次、报告日期占位、数据来源文件名
2. 摘要：3—5 句，每个数值后标注指标 id
3. 数据与方法：有效记录数（M01）、排除规则摘要、修订记录位置
4. 经营结果：M02、M03、M04 逐项列出并标注 id；不得出现未标注 id 的数字
5. 参与情况：M05、M06 逐项列出并标注 id；说明参与人次口径为不含工作人员
6. 分析结论：每条结论须指向至少一个指标 id 或一条纪要事实
7. 待确认事项：单列一节，逐条列出（不得写成结论）
8. 建议：与结论分开写，不得伪装成数据结论
9. 附录：一致性核对结果、制作工具说明
