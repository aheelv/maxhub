# 第 3 课素材包 · AI 智能问答助手与课程知识库

全部 FAQ、术语与评测题均为**课堂虚构数据**，不含真实学生信息与真实课程政策。

| 文件 | 用途 |
| --- | --- |
| 01_FAQ原始语料.csv | 30 条含重复、错别字、空答案、过期条目的原始语料 |
| 02_术语表.csv | 20 条术语与同义说法，用于别名扩展 |
| 03_越界问题清单.csv | 8 类必须拒答的问题 |
| 04_评测集.csv | 20 题（16 应答 + 4 拒答），含标准答案与标准处理 |
| 05_知识库模板.json | 知识条目字段定义与 1 条示例 |
| 06_提示词库.md | 7 类可复制提示词 |
| 07_评分表.csv | 100 分量规机器可读版 |

字段口径：`source` 记录原始语料行号；`scope` 只能取 课程内容/作业提交/工具使用/平台操作 四值之一。
