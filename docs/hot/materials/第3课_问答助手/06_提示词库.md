# 第 3 课提示词库 · 可整段复制

## P1 语料体检
读取 01_FAQ原始语料.csv，用脚本统计总行数、完全相同问题数、语义近似问题对、空答案行号、错别字/口语化行号、含「已停用/过期」行号，输出统计表与问题明细表（行号/原文/类型/建议处理）。不修改原文件。

## P2 清洗
按体检报告合并重复、删除过期、修正错别字、补全空答案（只能依据已有语料）；信息不足标「待补充」，严禁编造政策。输出 02_规范问答集.csv（qid,question,answer,source_rows,note）与合并映射表。

## P3 结构化
结合 02_术语表.csv 为每条生成 2—4 个别名，填 tags/source/scope/updated；answer 逐字取自规范问答集。生成 03_知识库.json 并用脚本校验 id 唯一、别名无冲突、answer 逐条一致。

## P4 拒答边界
把 03_越界问题清单.csv 的 8 类改写为可执行判定规则（rule_id/条件/处理/兜底话术/示例），另定义无命中处理、阈值 0.35 的低置信度拒答、并列最高分的处理。输出 04_拒答规则.md 与 05_规则配置.json。

## P5 问答页
生成单文件 06_问答助手.html：内嵌知识库与规则；越界检测 → 中文二元组重合度+关键词加权打分 → 阈值拒答 → 答案卡（显示 id/得分/命中别名/来源）；6 个示例问题按钮；零外部依赖、零网络请求。

## P6 评测
用与网页相同的逻辑写 Python 跑分脚本，对 04_评测集.csv 的 20 题逐题实跑，输出 08_评测结果.csv 与 07_评测报告.md（16 应答准确率、4 拒答正确率、总体正确率，均给分子分母；错题按类型归类与原因分析）。

## P7 修订
按错误类型执行补 aliases / 调越界关键词 / 调阈值 / 修正来源四类动作，实际修改 3 个文件后重跑同一评测集，输出修订前后对比表。禁止把标准答案硬编码进匹配逻辑。
