# 封面提示词模板

## 构图

竖版 2:3 书籍封面。画面主体：一张摊开的旧账册占据下半部，纸页边缘毛糙；账册上方悬着一枚静止的钟摆，投下一道斜长影子落在纸面上；背景是三条街的简化轮廓，层次由浅到深；上方三分之一留白用于放书名。

## 固定前缀（逐字复制）

书籍封面插画 竖版2:3 低饱和灰蓝与旧纸米色 柔和自然光 平视构图 细腻纸张纹理 无文字 无边框 16:9以外的竖幅 画面干净 上方三分之一留白

## 负面词

文字 书名 水印 品牌标识 真实人脸 多余肢体 手指畸形 高饱和霓虹 现代货币 硬币 纸币 二维码 边框 拼贴 噪点 过曝

## 使用说明

- 书名「账本城」由阅读版 HTML 以文字叠加，不让图像生成文字，避免错字。
- 若图像生成未启用，用纯 CSS 按同一构图（下半账册色块 + 斜长阴影 + 上方留白标题）绘制封面，并在制作说明中标注。
