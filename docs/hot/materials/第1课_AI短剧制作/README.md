# 第 1 课素材包 · AI 短剧一站式制作

全部素材为**课堂虚构数据**，仅用于教学演练，不含真实姓名、校名、品牌与肖像。

| 文件 | 用途 |
| --- | --- |
| 01_题材设定包.md | 选题与剧本的主题、时长、结构约束 |
| 02_人物卡.csv | 3 位人物的基础设定，图像锚点的来源 |
| 03_场景清单.csv | 6 个校园场景，剧本与分镜只能从中选取 |
| 04_原始事件素材.md | 10 条可改编的消费冲突事件 |
| 05_分镜表模板.csv | 8 镜分镜表的列定义与 1 行示范 |
| 06_提示词库.md | 8 类可整段复制的提示词 |
| 07_字幕模板.srt | SRT 格式与时间轴规则 |
| 08_片头片尾文案.md | 合规标识与素材来源声明模板 |
| 09_验收量表.csv | 100 分量规机器可读版 |
| 10_合规与授权清单.md | 逐项合规核对 |
| 示例_分镜图_01.png | WorkBuddy 实际生成的课堂示例分镜图（仅作风格参照，不得当作本人成果提交） |

使用方式：先在 WorkBuddy 中让助手清点本目录，再按课程全文第 0—9 步逐步取用。
