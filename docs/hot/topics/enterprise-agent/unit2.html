3索引与检索CourseRetriever(BaseRetriever)，简化 BM25 + min_score 阈值
4查询改写本单元保持原查询；生产可加多查询 / HyDE
5上下文组装format_docs() 生成 [source#chunk] 引用

检索阈值是本单元的关键护栏：min_score 过低会把无关片段当依据，因此另设输入护栏拦截范围外请求。

common/lc.py · CourseRetriever 类定义（节选）
class CourseRetriever(BaseRetriever):
    """简化 BM25 检索器：继承 LangChain BaseRetriever，可直接进入 LCEL。

    生产替换：Chroma / Milvus / pgvector + EnsembleRetriever + CrossEncoder rerank。
    """

    docs: List[Document] = Field(default_factory=list)
    k: int = 3
    min_score: float = 0.8
common/lc.py · 检索入口与 build_retriever
    def _get_relevant_documents(self, query: str, *, run_manager=None) -> List[Document]:
        return [d for d, s in self.search(query) if s >= self.min_score][: self.k]


def build_retriever(text: str, source: str = "policies.md") -> CourseRetriever:
    """Document -> RecursiveCharacterTextSplitter -> BaseRetriever，全 LangChain。"""
    splitter = RecursiveCharacterTextSplitter(
        chunk_size=120, chunk_overlap=20,
        separators=["\n\n", "\n", "。", "；", " "],
    )
    docs = splitter.create_documents([text], metadatas=[{"source": source}])
    for i, d in enumerate(docs):
        d.metadata["chunk"] = i + 1
    return CourseRetriever(docs=docs, k=2, min_score=0.8)
运行可见命中 签收 7 日内可无理由退货；对完全无关的问题返回空结果并触发拒答。

WRITE_TOOLS = {"create_refund"}


def tool_schemas() -> Dict[str, dict]:
    """工具清单即 JSON Schema，交给模型前先做白名单。"""
    return {name: t.args for name, t in TOOL_MAP.items()}
common/lc.py · call_tool 统一执行入口
def call_tool(name: str, args: Dict[str, Any], *, approved: bool = False,
              ledger: dict = None) -> dict:
    """统一执行入口：白名单 -> 参数校验 -> 写操作 HITL -> 幂等键 -> 审计。"""
    if name not in TOOL_MAP:
        return {"block": True, "reason": "工具不在白名单内"}
    if not isinstance(args, dict):
        return {"block": True, "reason": "参数必须是对象"}
    if name in WRITE_TOOLS and not approved:
        return {"block": True, "reason": "写操作需人工确认（HITL）"}
    key = name + "|" + json.dumps(args, sort_keys=True, ensure_ascii=False)
    if name in WRITE_TOOLS and ledger is not None and key in ledger:
        return {"ok": True, "idempotent": True, "result": ledger[key]}
    result = TOOL_MAP[name].invoke(args)
    if name in WRITE_TOOLS and ledger is not None:
        ledger[key] = result
    return {"ok": True, "idempotent": False, "result": result}

核心知识 · 工具安全三件套

白名单决定「能不能调」，HITL 决定「能不能写」，幂等键决定「会不会重复写」。

机制实现位置拦截对象失败时的返回
工具白名单TOOL_MAP + call_tool未注册工具{"block": true, "reason": "工具不在白名单内"}
人工确认 HITLWRITE_TOOLS + approvedcreate_refund 未确认{"block": true, "reason": "写操作需人工确认"}
幂等键ledger[name|args]重复提交{"ok": true, "idempotent": true}
企业级接入还会在这一层加入鉴权、速率限制与字段级脱敏；MCP / A2A 属于「工具与智能体间协议」，替换的是传输方式，不改变这里的白名单与审计原则。

# 全链由 LangChain Runnable 组成：① 输入护栏 -> ② 检索与只读工具（并行）
# -> ③ 组装上下文 -> ④ 离线模型生成带引用的答复
chain = RunnableLambda(lambda x: {
    "question": x["question"], "guard": guard_input(x["question"]),
}) | RunnableParallel(
    question=RunnableLambda(lambda x: x["question"]),
    blocked=RunnableLambda(lambda x: x["guard"]["block"]),
    reason=RunnableLambda(lambda x: x["guard"]["reason"]),
    context=RunnableLambda(lambda x: "" if x["guard"]["block"]
                           else format_docs(retriever.invoke(x["question"]))),
    facts=RunnableLambda(lambda x: [] if x["guard"]["block"]
                         else lookup({"question": x["question"]})),
) | mock_llm(compose)
链的四段依次为：输入护栏 → 并行检索 / 只读工具 → 上下文组装 → 生成答复。任何一段都可单独 .invoke() 验证。

def guard_input(question: str) -> dict:
    """① 输入护栏：范围外 / 越权 / 注入请求在检索之前就拦截，避免检索出无关片段后硬答。

    生产替换：把关键词表换成分类器 + 领域白名单 + 速率限制。
    """
    if len(question) > 200:
        return {"block": True, "reason": "输入超长"}
    for k in OUT_OF_SCOPE:
        if k in question:
            return {"block": True, "reason": "范围外或越权请求（" + k + "）"}
    return {"block": False, "reason": ""}

逐步开发流程 · 六步

  1. 准备 policies.md 语料，运行 02_rag.py 观察切分与命中。
  2. 运行 02_tools.py，确认白名单 / HITL / 幂等三种返回。
  3. 运行 02_agent.py，逐段 .invoke() 检查 context 与 facts。
  4. 加入 guard_input，确认范围外请求不会进入检索。
  5. 运行 02_eval.py 生成 unit2/eval_report.json。
  6. 对照评测报告，解释每个「引用 / 拒答 / 业务事实」判定。
