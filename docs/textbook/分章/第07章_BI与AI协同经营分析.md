# 《人工智能工具应用实践》

## 第 7 章　管理场景数据分析综合：BI × AI 协同

> **所属模块：**模块二 · AI 办公与数据分析　|　**学时：**2 课时（讲授 45 分钟 / 实践 45 分钟）　|　**课程主线定位：**先立口径，再谈自动化——把指标体系、对话式查询与报告生成串成可持续运行的分析流程

### 一、本章定位与主线

本章是模块二的收束，也是全书第一次要求学生处理「多人、多期、多口径」的真实管理问题。单个数字算得对，不等于整个组织的报告口径一致。章题、模块与学时不变，本次把导入与案例统一到「口径治理优先于工具自动化」这一主线上，并为下一章进入智能体编排做好流程化准备。

### 二、导入

同一份项目数据，财务、项目组与系统三张报表给出了三个「执行额」：207 万、192 万、180 万。三份报表都没算错，差别全在口径——含税与否、是否剔除已取消、按立项还是按支付确认。管理层看到的却是一句「数据打架」。

这类问题不能靠换一个更强的模型解决。课程案例页案例 02 记录了澳大利亚联邦银行宣布裁员 45 人、数周后撤回并道歉的公开事件，其教训正是「在验证之前就宣布结果」。本章据此把课程主线落到一套可运行的分析流程：先写口径卡，再做对话式查询，最后生成附带口径说明的经营报告。

### 三、学习目标与可检验能力

本章服务于「快速掌握并熟练使用最新 AI 工具、独立解决多类真实问题」的课程总目标，学完应能：

1. 说明指标体系与口径治理的基本结构，能为同一指标写出「财务 / 业务 / 系统」三种口径的定义与差异；
2. 用对话式 BI（NL2SQL）取数时，先确认口径与过滤条件，再核对 SQL 与取数结果；
3. 把三张报表的差额拆解为可逐项验证的口径差异，说明为何不得取平均或自行裁决；
4. 界定归因分析的边界：能说明「差异由哪些口径造成」，不越界声称因果；
5. 独立完成一份带口径卡、差额拆解与限制说明的一页纸经营报告。

### 四、核心知识点与知识递进

1. 指标体系与口径治理：指标名、业务定义、过滤条件、时间口径、责任部门五要素；
2. 同一指标的多种口径：含税 / 不含税、立项 / 支付、是否剔除已取消；
3. NL2SQL 与对话式 BI：自然语言转查询的便利与「口径未写明即被工具默认」的风险；
4. 差额拆解：把总差额分解为可逐项复算的口径差额，验证合计是否闭合；
5. 归因分析的边界与「先验证再宣布」的流程纪律；
6. 一页纸经营报告：结论、口径说明、关键数字、差额拆解、限制与下一步；
7. 分析与行动的衔接：报告须给出可执行的检查项，而非仅给出数字。

### 八、本章实践任务（面向真实问题）

**任务名称：**第 7 次课｜先立口径再谈自动化：27 万差额从哪来

**真实问题情境：**三张报表给出的执行额互不相同，管理层要求一份能说明「差额从哪来、以后怎么避免」的一页纸报告。你必须在报告中让每个数字都能追到口径定义，且不得取平均或自行裁决哪个数字才对。

**建议时长：**85 分钟（与课程网站已发布的第 7 次课练习资源包一致，≥60 分钟）　|　**完成方式：**单人独立完成，以 WorkBuddy 为主要工具

**主要工具：**WorkBuddy（表格读取、SQL／取数核对、报告生成、独立新会话复核）；浏览器核对案例与官方来源

**操作步骤：**

1. 读取 `orders_wide.csv`（17 行虚构教学数据），按财务 / 项目组 / 系统三种口径各写一张口径卡（五要素齐全）。
2. 分别复算三种口径的执行额，得到 A 2,070,000.00 元、B 1,920,000.00 元、C 1,800,000.00 元，并计算最大差额 270,000.00 元。
3. 把最大差额拆解为可逐项复算的口径差额（120,000 + 150,000），验证两项之和与总差额闭合。
4. 用对话式查询复现取数：先写明过滤条件，再核对生成的查询与结果；记录「若口径未写明，工具会默认什么」。
5. 撰写一页纸经营报告：结论、口径说明、关键数字、差额拆解、限制与下一步检查项；明确不声称因果。
6. 另开独立新会话仅依据口径卡复算差额，学生本人比对并签核；填写个人验收表并导出。

**成果要求：**

- 三张《指标口径卡》（五要素齐全）
- 《差额拆解表》（可逐项复算且合计闭合）
- 《对话式取数核对记录》（含查询与结果）
- 一页纸经营报告（含限制与下一步检查项）
- 独立新会话复算对照、本人签核说明与个人验收表

**配套资源：**课程网站第 7 次课资源包 `资源包_第7次课_BI口径卡与经营报告.zip`（https://aheelv.github.io/exercises.html）。
