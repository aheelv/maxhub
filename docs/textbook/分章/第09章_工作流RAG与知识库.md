# 《人工智能工具应用实践》

## 第 9 章　提示到编排：工作流、RAG 与知识库

> **所属模块：**模块三 · 智能体（Agent）技术　|　**学时：**2 课时（讲授 45 分钟 / 实践 45 分钟）　|　**课程主线定位：**从「写一条好提示」升级为「编排一条可验证的流程」——让每个答案都能追到出处

### 一、本章定位与主线

本章把第 8 章的单次端到端任务固化为可重复运行的流程。对经管类学生，真实问题往往不是「AI 会不会答」，而是「这次答的和上次是否一致、依据哪份文件、资料外的问题会不会礼貌拒答」。章题、模块与学时不变，本次把导入与案例统一到「可验证、可复用的流程」主线上，并补入 MCP 官方扩展中 Skills over MCP 这一最新机制。

### 二、导入

学院事务咨询里最常见的一问是：「奖助学金的申请截止日期是哪天？」学生把三份文件交给 AI，第一次答对了，第二次却给出了一份已废止通知里的日期；再问一个文件里根本没写的问题，它照样编了一个答案。三次对话，三种结果，问题不在提示词写得不够漂亮，而在缺少一条流程：资料如何切分与入库、检索命中哪一段、答案是否附出处、资料外如何拒答。

本章据此把课程主线从「会用智能体」推进到「会编排流程」：用工作流控制分支与循环，用 RAG 把答案锚定到资料，用知识库与技能把流程复用起来。MCP 官方扩展中的 Skills over MCP 更进一步，把「结构化工作流指令」变成可由客户端发现并调用的标准化能力。

### 三、学习目标与可检验能力

本章服务于「快速掌握并熟练使用最新 AI 工具、独立解决多类真实问题」的课程总目标，学完应能：

1. 说明工作流编排的四类控制（顺序、分支、循环、失败重试），能为一次知识问答画出流程图；
2. 拆解 RAG 五步链路（资料准备 → 切分 → 向量化与入库 → 检索 → 生成与附出处），并指出每一步的典型失效点；
3. 区分资料库与技能：前者存放可检索的知识，后者封装可复用的方法；能按任务判断该用哪一种；
4. 说明 Skills over MCP 等最新扩展如何把结构化工作流指令标准化，并理解其 opt-in 与协商要求；
5. 独立搭建一个带出处的知识问答流程，用测试集验证可答、资料外拒答与越权转人工三类表现。

### 四、核心知识点与知识递进

1. 工作流四类控制与「可验证中间产物」的设置；
2. RAG 五步链路与失效点：切分过粗/过细、检索未命中、命中但排序靠后、生成脱离引用、出处缺失；
3. 资料库（知识）与技能（方法）的区别；book-to-skill 把一本书转为可调用技能的思路；
4. 测试集设计：可答题、资料外题、越权题三类，以及命中率、忠实度、拒答率的观测口径；
5. MCP Skills over MCP 扩展：面向智能体工作流的结构化指令，opt-in、须双方显式支持并在初始化时协商；
6. 独立会话隔离：检索／生成会话不得预先拿到测试集标准答案，避免实验污染。

### 七、真实案例（背景 · 适用知识点 · 来源 · 实践任务）

#### 案例 9-1　Skills over MCP：把流程变成可发现、可调用的能力　`A 类 · 可核验官方扩展`

- **案例背景：**MCP 官方扩展总览列出 Skills over MCP（面向智能体工作流的结构化丰富指令，通过 MCP 被发现与消费）、Tasks（长任务异步执行、轮询与持久句柄）与 MCP Apps（会话内交互式 UI）；页面明确所有扩展均为 opt-in，须客户端与服务端显式支持并在初始化时协商。
- **适用知识点：**技能与知识库的区别、工作流标准化、扩展协商
- **来源／使用场景：**https://modelcontextprotocol.io/extensions/overview（图 S17 为真实页面截图）；基础协议见 https://modelcontextprotocol.io/specification/2026-07-28（图 S16）。

### 八、本章实践任务（面向真实问题）

**任务名称：**第 9 次课｜带出处的知识问答：12 题测试集与可复核工作流

**真实问题情境：**学院事务咨询需要一套稳定的问答流程：可答的问题必须附出处，资料外的要拒答，越权的要转人工，且每次运行的结果可被复核。你要交付流程本身与验证记录，而不只是一段对话。

**建议时长：**85 分钟（与课程网站已发布的第 9 次课练习资源包一致，≥60 分钟）　|　**完成方式：**单人独立完成，以 WorkBuddy 为主要工具；检索／生成会话与核验会话相互隔离

**主要工具：**WorkBuddy（资料库、技能安装与调用、工作流编排、独立新会话盲测）；浏览器核对 MCP 官方扩展与平台文档

**操作步骤：**

1. 读取第 9 次课资源包中的四份 KB 文档（共 24 条，虚构教学数据），建立资料库并写出切分规则与失效点预案。
2. 绘制工作流流程图，标出顺序、分支、循环与失败重试四类控制，以及每步的可验证中间产物。
3. 安装并调用一个技能（如 book-to-skill 思路），说明「技能封装方法」与「资料库存放知识」的差别。
4. 用 12 题测试集盲测：检索／生成会话不得预先拿到标准答案；分别记录可答 7 题、资料外 3 题、越权 2 题的表现。
5. 逐条核对可答题的引用出处是否真实存在于 KB 文档；统计命中率、忠实度与拒答情况，写出失效点归因。
6. 另开独立新会话以审校员视角复核引用与拒答，学生本人签核；填写个人验收表并导出流程说明与验证记录。

**成果要求：**

- 《RAG 五步链路与失效点说明》（含切分规则）
- 《工作流流程图》（四类控制与可验证中间产物）
- 《12 题测试集结果表》（三类题分组统计）
- 《引用出处核对记录》与《失效点归因》
- 技能与资料库区别说明、独立新会话审校记录、本人签核说明、个人验收表

**配套资源：**课程网站第 9 次课资源包 `资源包_第9次课_知识库RAG与工作流.zip`（https://aheelv.github.io/exercises.html）。
