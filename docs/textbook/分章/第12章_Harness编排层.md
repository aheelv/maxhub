# 《人工智能工具应用实践》

## 第 12 章　什么是 Harness：模型之外的编排层

> **所属模块：**模块四 · Harness 与 AI 集成开发环境（重点模块）　|　**学时：**2 课时（讲授 45 分钟 / 实践 45 分钟）　|　**课程主线定位：**拆开智能体运行时——同一个模型，为什么换一套编排层，结果与成本都变了

### 一、本章定位与主线

本章是课程重点模块四的开篇，也解释了全书从第一页就埋下的那句「模型决定能力上限，编排决定实际下限」。章题、模块与学时不变，本次把智能体集成平台与开源 Harness 作为同一条技术主线的两种形态来对照，并把导入与案例统一到「理解成本与可控性从哪来」这一主线上。

### 二、导入

同一个模型，交给不同工具完成同一份表格整理任务：一次输出干净、一次漏掉两列，用量还差了几倍。学生很容易得出「模型不稳定」的结论，但真正起作用的往往是模型之外的那一层——系统提示写了什么、工具清单怎么给、仓库规则有没有注入、执行轨迹是否只追加、权限与沙箱划到哪。

本章把这一层命名为 Harness（编排层／运行时）并拆成五层与四项组成，以 WorkBuddy 与 DeepSeek Harness 两个可核验实例对照说明：前者是面向普通用户的智能体集成平台，后者是开源的智能体运行时。课程主线在此从「会治理多智能体」推进到「会看懂并评估编排层」。

### 三、学习目标与可检验能力

本章服务于「快速掌握并熟练使用最新 AI 工具、独立解决多类真实问题」的课程总目标，学完应能：

1. 说明 Harness 的定义与「模型之外」的边界，能指出一次任务中哪些行为来自模型、哪些来自编排层；
2. 复述五层分层与四项组成，并说明每层缺失会导致什么可观察的问题；
3. 对照 WorkBuddy 与 DeepSeek Harness 两种形态，说明智能体集成平台与开源运行时在用户、扩展方式与可观测性上的差别；
4. 解释脚手架 Token 成本从哪来，能列出三项可执行的成本约束；
5. 独立完成一次「同一任务、不同编排配置」的对照记录，并用只追加轨迹说明差异来源。

### 四、核心知识点与知识递进

1. Harness 的定义：包在模型外层的运行时，负责上下文组装、工具注册、循环控制、权限与轨迹；
2. 五层分层：模型层、上下文层、工具层、循环／编排层、治理与可观测层；
3. 四项组成：系统提示与规则、工具 schema 与注册、循环与终止条件、轨迹与权限；
4. 两个实例对照：WorkBuddy（智能体集成平台，面向普通用户）与 DeepSeek Harness（开源运行时，developer preview）；
5. 脚手架 Token 成本：默认系统提示、工具定义、注入的仓库规则与技能摘要都计入输入；
6. 三项成本约束：精简上下文、按任务选择预设、设置用量与步数上限；
7. 「能跑不等于正确」：执行成功与结果正确是两件事，须以可复核产物验收。

### 八、本章实践任务（面向真实问题）

**任务名称：**第 12 次课｜Harness：模型之外的编排层——结构与成本对照

**真实问题情境：**同一份表格整理任务在两种编排配置下给出不同结果与用量。你要用五层分层与四项组成解释差异来源，并用只追加轨迹与用量记录佐证，而不是笼统归因于「模型不稳定」。

**建议时长：**80 分钟（与课程网站已发布的第 12 次课练习资源包一致，≥60 分钟）　|　**完成方式：**单人独立完成，以 WorkBuddy 为主要工具；对照与审校用独立新会话实现

**主要工具：**WorkBuddy（任务配置、上下文精简、轨迹查看、独立新会话）；浏览器核对官方帮助文档、MCP 规范与 AI Index 官方页

**操作步骤：**

1. 在浏览器中核对 WorkBuddy 官方帮助文档六项核心能力、MCP 2026-07-28 规范角色定义与 AI Index 2026 智能体数据，写《依据摘录卡》。
2. 用同一份虚构教学数据、同一任务，在两种编排配置下各跑一次（如「完整上下文」与「精简上下文 + 明确终止条件」），保存两次输出与轨迹。
3. 按五层分层逐层标注两次配置的差异，说明每层差异可能导致的可观察后果。
4. 记录两次的上下文构成与 Token 用量估算，把固定脚手架成本单独列出；列出三项可执行的成本约束。
5. 用只追加轨迹说明「能跑不等于正确」：找出执行成功但结果有误的一处，写出人工复核规则。
6. 另开独立新会话以审校员视角只依据轨迹与输出复核，学生本人签核；填写个人验收表并导出。

**成果要求：**

- 《依据摘录卡》（官方文档 / 规范 / 报告各至少一条，含 URL）
- 《五层分层差异对照表》与两次输出、轨迹记录
- 《脚手架成本估算表》与三项成本约束
- 《能跑不等于正确复核规则》
- 独立新会话审校记录、本人签核说明、个人验收表

**配套资源：**课程网站第 12 次课资源包 `资源包_第12次课_Harness结构与成本.zip`（https://aheelv.github.io/exercises.html）。

### 十一、本章小结

本章把「模型决定能力上限，编排决定实际下限」讲透：五层分层与四项组成，解释了同一个模型为何在不同工具里结果和成本都不同。智能体集成平台与开源运行时是同一主线的两种形态，而权限、轨迹与终止条件正是把能力变成可控交付的关键。下一章进入 AI IDE 与编程智能体，把这套运行时真正用起来。
