# 《人工智能工具应用实践》

## 第 11 章　多智能体协作与 AgentOps

> **所属模块：**模块三 · 智能体（Agent）技术　|　**学时：**2 课时（讲授 45 分钟 / 实践 45 分钟）　|　**课程主线定位：**当一台智能体不够用：用分工、轨迹与成本约束，把复杂任务管到可控

### 一、本章定位与主线

本章是模块三的收束。前两章把单次任务与可复用流程交付出来，本章处理「任务复杂到一台智能体不够用」时的工程问题：如何分工、如何看懂执行轨迹、如何在跑偏时回滚、如何把成本与失败模式纳入治理。章题、模块与学时不变，本次补入 MCP Tasks 扩展等最新机制，把导入与案例统一到「可控」这一主线上。

### 二、导入

一次跨部门的市场调研任务被交给智能体：搜集资料、整理数据、写报告、再自查一遍。全部塞进一个会话的结果是——写到一半把前面搜集的口径忘了，自查环节又直接沿用了撰写者的说法，等于自己给自己打分。

这类问题的解法不是换个更大的模型，而是工程上的分工与隔离：把任务拆成角色、用子代理或专家团分别执行、让审校角色只拿被审校的产物，再用只追加的执行轨迹（Trajectory）记录每一步，配上成本预算与失败回滚。MCP 官方扩展中的 Tasks 正是为长任务异步执行、轮询与持久句柄而设。本章据此把课程主线从「会装配」推进到「会治理」。

### 三、学习目标与可检验能力

本章服务于「快速掌握并熟练使用最新 AI 工具、独立解决多类真实问题」的课程总目标，学完应能：

1. 说明四种协作拓扑的适用场景，能为给定任务选择拓扑并写出理由；
2. 使用子代理与专家／专家团机制拆分任务，并设置角色间的信息隔离，避免自己审自己；
3. 读懂只追加的执行轨迹（Trajectory），定位跑偏步骤并执行一次失败回滚演练；
4. 为多智能体任务设置成本预算与上限，说明脚手架 Token 与并行任务带来的成本结构；
5. 独立完成一次协作方案设计与跑偏排查，产出可观测、可回滚、成本受限的交付记录。

### 四、核心知识点与知识递进

1. 四种协作拓扑：串行流水线、并行分治、主从分派、评审闭环；各自的适用与失效条件；
2. 子代理机制与专家／专家团：角色边界、输入隔离、产物交接；
3. Trajectory 只追加日志：记录什么、为什么不能改写、如何用于复盘与回滚；
4. AgentOps 三件事：可观测性、成本控制、失败模式识别；
5. MCP Tasks 扩展：长任务异步执行、轮询、持久句柄，以及 opt-in 与初始化协商要求；
6. 常见失败模式：口径漂移、自我审校、无限循环、越权写入、成本失控；
7. 独立会话隔离原则在多人协作模拟中的应用：同一账号下的独立新会话扮演审校员／评委，最终判断由学生本人签核。

### 八、本章实践任务（面向真实问题）

**任务名称：**第 11 次课｜多智能体协作与 AgentOps：方案设计、跑偏排查与回滚

**真实问题情境：**一次跨部门调研任务复杂到单会话无法可靠完成。你要设计一套分工方案，让角色之间信息隔离、执行过程可观测、跑偏可回滚，并把成本控制在预设上限内。

**建议时长：**85 分钟（与课程网站已发布的第 11 次课练习资源包一致，≥60 分钟）　|　**完成方式：**单人独立完成，以 WorkBuddy 为主要工具；审校／评委视角用同一账号下的独立新会话模拟，最终判断由本人签核

**主要工具：**WorkBuddy（任务拆分、专家或专家团、子代理、执行轨迹查看、独立新会话）；浏览器核对 MCP 官方扩展与平台文档

**操作步骤：**

1. 把任务拆成至少四个角色（资料搜集、数据整理、报告撰写、独立审校），画协作拓扑图并写出选择理由。
2. 为每个角色写明输入范围与禁止接触的信息；审校角色的会话不得拿到撰写者的自评结论，避免自我审校。
3. 定义不少于三项评估指标与成本预算上限（区分固定脚手架成本、每步增量与并行倍数），写出超限时的处置。
4. 运行一次协作流程，查看只追加的执行轨迹，逐步标注角色、输入与产物。
5. 按资源包中的虚构轨迹完成一次跑偏排查与回滚演练：定位跑偏步骤、说明影响范围、执行回滚并记录。
6. 另开独立新会话以评委视角只依据轨迹与产物复核，学生本人签核最终判断；填写个人验收表并导出。

**成果要求：**

- 《协作拓扑图与角色边界说明》
- 《评估指标与成本预算说明》（含超限处置）
- 《执行轨迹标注》与《跑偏排查与回滚记录》
- 防止自我审校的隔离规则、独立新会话评委记录、本人签核说明、个人验收表

**配套资源：**课程网站第 11 次课资源包 `资源包_第11次课_多智能体与AgentOps.zip`（https://aheelv.github.io/exercises.html）。
