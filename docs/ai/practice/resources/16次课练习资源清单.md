# 16 次课练习资源清单

每课一个 ZIP，内含任务单、背景资料、素材数据、操作模板、个人验收表与教师核验卡。
网页下载入口：`site/exercises.html`（课程门户完整下载页，16 课卡片 + 逐份资料）、`site/index.html#exercise-downloads`（首页按课次直达 ZIP）、`site/resources.html#exercise-downloads`（拓展资源页下载通道）、`course-exercises-site/index.html`（独立练习资源站，16 课任务详情与逐份下载）。主站若以 `site/server.js` 启动，`/downloads/` 下的文件均以附件形式下载。
