# 第 15 次课｜WorkBuddy 功能覆盖清单

> 校园活动报名应用 · 100 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 云服务与数据库 | 按数据模型建表并说明字段 | data-model.csv 与结构说明 | ☐ |
| 用户认证与权限 | 未登录不可提交、列表仅管理员可见 | 验收用例记录 | ☐ |
| 文件存储决策 | 说明哪些数据放云端、哪些不放 | file-storage-decision.csv | ☐ |
| 页面生成与改造 | 生成报名页并调整移动端布局 | 页面截图或草案 | ☐ |
| 发布 / 分享链接 | 按变更清单确认后发布；未授权则标模拟 | 链接截图或「模拟/未上线」 | ☐ |
| 上线验收与回滚 | 功能 6 项 + 安全 5 项逐条过并写回滚 | release-checklist.csv | ☐ |

共 **6 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
