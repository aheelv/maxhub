## 一、任务说明

### 主题对应

对应课件《大语言模型：从 n-gram 到 Transformer 与推理模型》：预测下一个词、Token 与分词、上下文窗口、注意力与长上下文代价、推理模型的「思考」也是消耗、结构化提示四要素（角色 / 任务 / 约束 / 格式）、以及「这份活值不值得交给 AI」的四步成本估算。

### 题目背景（背景资料）

校园「旧书循环站」要把一批读者留言整理成月度简报。上一届同学的做法是把 60 条留言一次性粘进对话框反复追问了 6 轮，结果前后口径不一致、还把两处数字说错。你这轮要独立用 WorkBuddy 做一次对照实验：同一份材料，分别用「模糊提示 + 多轮追问」和「四要素结构化提示 + 一轮交付」跑两遍，用量与结果都留证；再结合给定的虚构计价表，算出两种做法的成本差，判断这类活是否值得交给 AI、以及该把哪一段交给 AI。材料中 token_price.csv 是课堂虚构单价，不得替换为真实商用价格。

### 本课大题

**由你一人用 WorkBuddy 完成《Token 与上下文成本实测报告》：两轮对照实验记录、一份四要素结构化提示、一张成本估算表，以及一句有数字支撑的「值不值得」结论。**

### 独立完成规则

全程单人完成。两轮实验必须在互不共享上下文的新会话中进行，避免前一轮结果污染后一轮；用量若产品不显示，按 usage_samples.csv 的课堂模拟读数人工记录并标注「模拟读数」，不得编造为真实计费。

## 二、所需素材

本包内全部文件均为课堂虚构材料，解压后一次性上传到 WorkBuddy 本课工作区：

| 文件 | 用途说明 |
| --- | --- |
| `reader_notes.txt` | 60 条虚构读者留言，含 3 条重复、2 条空内容与 2 条数字口误，供整理 |
| `token_price.csv` | 3 个课堂虚构模型的输入/输出单价（每千 token，¥） |
| `usage_samples.csv` | 5 次课堂模拟用量记录：输入/输出 token、轮次、是否复用上下文 |
| `vague_prompt.txt` | 上一届使用的模糊提示，作为对照基线 |
| `L2-成本估算表.csv` | 四步估算模板：任务量 / 单次 token / 单价 / 人工替代耗时 / 判断 |
| `L2-实验记录.csv` | 两轮实验的对照字段：轮次、提示形态、输出字数、口径一致性、读数 |
| `L2-验收表.csv` | 9 项验收项与通过标准 |

另附 `教师核验卡.txt`（**建议完成后再看**）与 `使用说明.md`（16 课通用规程）。

### 固定核验结果（自检用）

1. reader_notes.txt 共 60 条，其中重复 3 条、空内容 2 条、含数字口误 2 条；有效唯一留言 55 条。
2. token_price.csv 中单价最低的是「轻量档」：输入 0.002 / 千 token，输出 0.006 / 千 token；最高的是「推理档」。
3. usage_samples.csv 的 5 次记录中，复用上下文的那次输入 token 明显更高，用于说明「长会话的隐形开销」。
4. 四要素结构化提示必须同时含角色、任务、约束、格式；缺任一项判为不合格。
5. 成本估算的四步口径：①任务量→②单次 token 估计→③按单价折算→④与人工耗时/质量对照；不得只报一个总价。

## 三、详细操作步骤（合计 70 分钟）

**步骤 1｜8 分钟｜冻结材料与通用准备**

在 WorkBuddy 新建工作区，上传全部 7 个文件，输出目录 L02-个人-Token实测-v1。发通用准备提示词，明确「单价只取 token_price.csv、用量只取 usage_samples.csv、不得联网查真实价格」。要求它先复述四步成本估算口径与「两轮必须独立会话」这一限制。

**步骤 2｜12 分钟｜体检输入材料**

让 WorkBuddy 统计 reader_notes.txt 的总条数、重复条数、空内容条数、含数字口误的条数，并给出有效唯一留言数；你本人打开文件逐条数一遍核对，填入 L2-验收表.csv 前 3 项。再让它解释：为什么「60 条一起塞进去」会让上下文随轮次增长——要求用「输入 token 被反复携带」这一机制说清，不许只答「因为很长」。

**步骤 3｜14 分钟｜第一轮：模糊提示 + 多轮追问（对照基线）**

新开会话 A，先上传 reader_notes.txt，逐字发送 vague_prompt.txt 的模糊提示，然后按真实习惯追问至少 3 轮（例如「再短点」「加个数字」「刚才那个数改一下」）。保存每一轮的原始提示与回答，记录累计轮次、各轮输入/输出读数（产品不显示则按 usage_samples.csv 对应记录人工填写并标「模拟读数」）。检查最终稿里是否出现前后口径不一致或把口误数字当真。

**步骤 4｜14 分钟｜第二轮：四要素结构化提示 + 一轮交付**

新开会话 B，不复制会话 A 的任何结论，只上传同样的 reader_notes.txt。把 vague_prompt 改写成同时包含角色、任务、约束、格式的四要素提示（例如：角色=校园运营分析员；任务=整理三条月度要点；约束=不超过 200 字、保留原始数字、剔除重复与空内容、口误数字标「需核验」；格式=指标/数值/解读 三列一轮给全）。争取一轮定稿，记录读数与是否一次通过。

**步骤 5｜12 分钟｜算钱：四步成本估算**

把 usage_samples.csv 的 5 次记录按 token_price.csv 折算成 ¥，填入 L2-成本估算表.csv；再分别算两轮实验各自的输入+输出成本，给出差额与「多轮追问多花了多少」。最后补上第四步：与人工整理 60 条留言的估计耗时、以及两轮质量差异对照，写出「哪一段值得交给 AI、哪一段必须人工核」。所有算式要在表里可见，不能只给结果。

**步骤 6｜10 分钟｜独立复核与一页结论**

新开 WorkBuddy 独立审校会话，只给原始文件与验收标准，让它独立核对有效唯一留言数、两轮读数差额与四要素是否齐全；与你比对。最后写一页《Token 与上下文成本实测报告》，含一句有数字支撑的结论（例如「结构化提示把 4 轮压到 1 轮，输入 token 减少约 X，且未出现口径漂移」），并明确标注哪些数字是课堂模拟读数。

> 步骤分钟合计：**70 分钟**（与任务时长一致）。

**通用准备提示词**

```text
你是我的课堂 AI 项目助理。我将独立完成本课任务，请只根据我上传的本课任务单和配套资料工作。先输出目标、输入文件及版本、必须遵守的限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单。此轮只做计划，不写文件、不访问网络、不连接服务、不发布。
```

**四要素改写**

```text
把下面这句模糊提示改写成同时包含【角色】【任务】【约束】【格式】四要素的版本，并在改写后用四行标注每个要素分别对应哪一句。约束里必须包含：不超过 200 字、保留原始数字、剔除重复与空内容、可疑数字标注「需核验」而不是自行修正。不要替我编造任何数字。
```

**成本估算**

```text
只读 token_price.csv 与 usage_samples.csv。逐行计算：输入成本 = 输入token/1000 × 输入单价，输出成本同理，合计保留 4 位小数。再指出哪一行因为复用上下文而输入最高，并用一句话解释原因。表格里必须保留算式文本，不许只给金额。不得联网查真实价格。
```

**独立审校（新会话）**

```text
你是独立审校员，只拿到原始素材与验收表。请独立给出：有效唯一留言条数、四要素提示缺项检查、两轮输入 token 差额。每项写明依据文件与行号；无法判断写「需核验」。
```

## 通用执行规程（16 次课通用，单人独立完成）

1. **独立工作区**：每位学生在 WorkBuddy 中新建本课工作区，一次上传本包内全部素材；提示中声明「本课只能使用这些材料」。输出目录按 `L课次-个人-成果名-v版本` 命名。
2. **先计划、后动手**：先发「通用准备提示词」，要求 WorkBuddy 只输出目标理解、输入文件与版本、必须遵守的限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单；**此轮不写文件、不联网、不连接服务、不发布**。你本人逐项确认计划后，再让它一次完成一个工作包。
3. **独立复核**：需要第二视角时，在同一账号下**新开独立会话**扮演审校员，只提供原始材料与验收规则，**不把前一会话的结论透露给它**。同一会话既执行又自证，判为无效。
4. **逐条验收**：用文件字段、算式、测试输出、可见运行页面或独立审查会话作证。**WorkBuddy 说「已完成」不等于通过**；每步保留输入、产物/工具结果、检查结果与下一步。
5. **可观察留证**：保留可见的提示词、工具结果、文件差异、测试与运行结果；不要求、也不保存模型隐式思维链。
6. **安全边界**：练习包内全部为虚构数据与演示身份。不得上传真实学号、手机号、身份证、账号口令或正式密钥。若 WorkBuddy 请求改动超出任务范围、接触个人数据、访问未授权路径、调用外部服务或公开发布，**立即暂停并由你本人确认**；无授权则采用任务单中的「模拟替代」，并显式标注「模拟 / 未启用 / 未上线」，不得把文字草案说成已连接、已触发或已上线。
7. **错误处理**：保留错误版本与可观察记录，另存 `v0-failed`，不覆盖固定输入与测试预期；先找第一次偏离验收要求的位置，再修正、重跑、留下前后对比证据。
8. **提交**：按本任务单「提交清单」逐项勾选，未通过项、模拟项和未知项都要显式写明。成果物命名带课次、个人标识与版本号。

> 评分：每课评价要点合计 100 分。步骤分钟数相加等于本课任务时长；建议按分钟推进，最后留 8—10 分钟做独立复核与归档。
