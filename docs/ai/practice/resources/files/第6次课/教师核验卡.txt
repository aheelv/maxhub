1. sales_march.csv 共 78 行：已支付 70、已退款 5、测试单 3。分析只用 70 行；测试单金额 9999 是明显诱饵，若进入合计必错。
2. 各店 3 月有效营收 / 有效订单数 / 客单价（不含税，元）：
   A店：290.00 / 4 单 / 客单价 72.50
   B店：1043.00 / 14 单 / 客单价 74.50
   C店：732.00 / 13 单 / 客单价 56.31
   D店：777.00 / 13 单 / 客单价 59.77
   E店：1053.00 / 13 单 / 客单价 81.00
   F店：867.00 / 13 单 / 客单价 66.69
   有效总计 = 4762.00 元；分组小计之和必须与之相等。
3. 2 月汇总与环比（环比 = (3月-2月)/2月）：
   A店：2月 1180 → 3月 290.00，环比 -75.42%
   B店：2月 920 → 3月 1043.00，环比 +13.37%
   C店：2月 1080 → 3月 732.00，环比 -32.22%
   D店：2月 860 → 3月 777.00，环比 -9.65%
   E店：2月 1340 → 3月 1053.00，环比 -21.42%
   F店：2月 760 → 3月 867.00，环比 +14.08%
   环比下降超过 2% 的门店：A店、C店、D店、E店。
4. A 店有效订单仅 4 单，客单价高属小样本，不能推出「最该扩店」；三类误用（相关当因果、基数错误、幸存者偏差）各须至少命中一次。
5. 图型：门店间比较→柱图；两月趋势→折线（或双色柱）；金额分布→直方图。柱图纵轴须从 0 起并标单位（承接第 3 课）。
6. 四步必须逐步打印中间结果；AI 直接给结论不打印中间结果即判不通过。若产品不能执行代码，可改表格计算并逐步截图，但须标注「未执行代码」。
