# 第 13 次课｜WorkBuddy 功能覆盖清单

> AI IDE CSV检查器 · 90 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 代码文件读取与改写 | 读仓库、改指定文件、不动其他目录 | 改动前后文件差异 | ☐ |
| 运行与测试 | 真实跑测试并保留输出 | 测试输出与轨迹表 | ☐ |
| 任务书生成 | 把一句需求写成含文件/行为/测试的可验收任务 | 可验收任务书 | ☐ |
| Trae 对照（可选） | 用 AI IDE 观察读—改—跑—看闭环 | 对照记录或「未启用」标注 | ☐ |
| 审查清单 | 按清单验收一次改动并识别作弊手法 | 审查清单.csv | ☐ |
| 版本留证 | 保留失败版本与回归结果 | v0-failed 与回归记录 | ☐ |

共 **6 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
