# 第 3 次课｜WorkBuddy 功能覆盖清单

> 多模态读图与素材生成 · 75 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 图表 / 图像生成 | 按四要素提示生成双坐标轴图 | chart_gen.png 与生成提示全文 | ☐ |
| 多模态读图 | 新会话只凭图片读回 6×2 数值 | 盲读原始回答 | ☐ |
| 文件读取与比对 | 真值表逐格比对并标证据位置 | L3-读图核验表.csv | ☐ |
| few-shot 文案生成 | 给示例后按同格式产出 3 条文案 | 示例与 3 条文案 | ☐ |
| 多会话独立审校 | 审校会话独立指出错误类别与违规数字 | 审校提示与回复 | ☐ |

共 **5 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
