## 一、任务说明

### 主题对应

对应课件《用自然语言做数据分析：代码解释器与 AI 分析师》：把模糊问题拆成口径清楚的四步分析、AI 写代码并真实执行、为三类关系各选一种合适的图、每步打印中间结果并用分组小计校验总量、以及三类统计误用（相关当因果、百分比基数错误、幸存者偏差）。

### 题目背景（背景资料）

「校园文创小店」有 6 个门店 3 月的订单明细和 2 月对照数据。店长问「看看有什么问题」，这是一句无法执行的提问。更糟的是，上一届同学据此得出「A 店客单价高所以最该扩店」的结论，但那家店的订单里混着未剔除的退款单，且样本只有 4 单。你要独立用 WorkBuddy 把这句模糊提问改写成口径清楚的四步分析，让 AI 写脚本真实执行、每步打印中间结果，用分组小计校验总量，为三类关系各选一种图，最后用三类误用清单给自己的结论挑刺。

### 本课大题

**由你一人用 WorkBuddy 完成《3 月门店经营分析报告》：一份带口径的四步分析任务书、可复现脚本与中间结果、三张选对图的图表、三条带数字的结论，以及一张误用排查表。**

### 独立完成规则

全程单人完成。「分析」与「挑刺」必须用两个独立会话：挑刺会话只拿到脚本、结果与数据，不拿到你的结论措辞。AI 说「已执行」不等于真的跑过，必须以打印出的中间结果和分组小计为证。

## 二、所需素材

本包内全部文件均为课堂虚构材料，解压后一次性上传到 WorkBuddy 本课工作区：

| 文件 | 用途说明 |
| --- | --- |
| `sales_march.csv` | 3 月订单明细：门店、金额（不含税）、状态（已支付/已退款/测试单）、日期 |
| `sales_february.csv` | 2 月各门店汇总，用于环比 |
| `analysis_brief.txt` | 店长那句模糊提问 + 本课固定口径说明 |
| `L6-四步分析表.csv` | 模板：步骤 / 口径 / 中间结果 / 校验方式 |
| `L6-图表选择表.csv` | 三类关系（比较 / 趋势 / 分布）与图型对照模板 |
| `L6-误用检查表.csv` | 三类统计误用共 9 个检查项 |
| `L6-验收表.csv` | 10 项验收项与通过标准 |

另附 `教师核验卡.txt`（**建议完成后再看**）与 `使用说明.md`（16 课通用规程）。

### 固定核验结果（自检用）

1. 固定口径：只计「已支付」订单，金额不含税，剔除退款与测试单，时间 2026-03-01 至 03-31。
2. sales_march.csv 共 78 行，其中已支付 70 行、已退款 5 行、测试单 3 行；分析只用 70 行。
3. 分组小计之和必须等于 70 行有效金额总计；不相等说明筛选或分组有误。
4. A 门店有效订单只有 4 单，客单价高属于小样本，不能推出「最该扩店」。
5. 三类误用至少各命中一次：相关当因果、百分比基数写错、只看留下来的店（幸存者偏差）。

## 三、详细操作步骤（合计 80 分钟）

**步骤 1｜8 分钟｜冻结材料与口径确认**

新建工作区上传 7 个文件，输出目录 L06-个人-经营分析-v1。发通用准备提示词，让 WorkBuddy 先复述固定口径（已支付 / 不含税 / 剔除退款与测试单 / 3 月），并说明「先给计划不跑数」。口径复述不全就先纠正，不进入分析。

**步骤 2｜16 分钟｜把模糊提问改写成四步任务书**

把 analysis_brief.txt 里「看看有什么问题」改写成四步可执行分析：①按口径筛选并打印各类状态行数 ②按门店算营收与客单价 ③与 2 月对照算环比、标出下降超过 2% 的门店 ④用分组小计校验总量。每一步在 L6-四步分析表.csv 写清「输入、口径、应打印的中间结果、校验方式」。要求 WorkBuddy 明确「每步打印中间结果，不许直接给结论」。

**步骤 3｜18 分钟｜让 AI 写脚本、真实执行、逐步留证**

让 WorkBuddy 按四步任务书写出可复现脚本并真实运行，保存脚本文件与每一步打印输出。你本人核对：状态行数是否为 70/5/3、各门店分组小计相加是否等于有效总计、环比用的是 2 月汇总表而不是 3 月自比。若产品不能执行代码，改用表格公式逐步计算并把每步结果截图，标注「表格计算 / 未执行代码」，不得声称已运行脚本。

**步骤 4｜16 分钟｜三类关系各选一种图，并写可验证结论**

按 L6-图表选择表.csv 为「门店间比较 / 两月趋势 / 订单金额分布」各选一种图（柱图 / 折线 / 直方图），说明为什么不选另外两种。每张图配一句能被验证的结论，句中必须有具体数字且能回到分组小计。让 WorkBuddy 生成图后，你检查坐标轴是否从 0 起、单位是否标注（承接第 3 课读图教训）。

**步骤 5｜14 分钟｜挑刺：三类统计误用自查**

新开独立会话，只给脚本、打印结果、两张数据表与 L6-误用检查表.csv，不给你的结论措辞。请它逐项检查 9 个检查项，重点追问「A 店 4 单能否推出扩店结论」「环比百分比的分母写对了吗」「只看还在营业的店会漏掉什么」。把命中项填进检查表，并回去修订三条结论：凡小样本、基数不明、只看幸存者的表述都要加限定语。

**步骤 6｜8 分钟｜对账、归档与验收**

让 WorkBuddy 汇总一页《3 月门店经营分析报告》，含口径、四步中间结果、三张图、三条修订后结论、误用检查命中项。填写 L6-验收表.csv 10 项，特别确认「分组小计 = 总计」与「脚本可复跑」。归档脚本、输出日志、图与报告。

> 步骤分钟合计：**80 分钟**（与任务时长一致）。

**四步任务书**

```text
把「看看有什么问题」改写成四步可执行分析。固定口径：只计已支付订单、金额不含税、剔除退款与测试单、时间 2026-03-01 至 03-31。每步写清输入文件、筛选条件、应打印的中间结果、校验方式。要求：每步先打印中间结果再进入下一步，禁止直接给最终结论；最后用分组小计之和校验总量。
```

**执行与留证**

```text
按四步任务书写一段可复现脚本并真实运行。请逐步打印：①三种状态各多少行 ②各门店营收、有效订单数、客单价 ③与 sales_february.csv 对照的环比 ④分组小计之和与有效总计是否相等。保留脚本与全部打印输出；若无法执行代码，明确说明并改为逐步表格计算，不要假装已执行。
```

**独立挑刺（新会话）**

```text
你是独立审查员，只拿到脚本、运行输出、两张数据表和误用检查表，没有看过任何人的结论。请逐项检查：相关是否被当成因果、百分比的分母是否写对、是否只看留下来的门店而忽略已关停或零订单门店、小样本是否被过度推广。每项给「命中 / 未命中 + 依据行号或输出」，并指出哪条结论需要加限定语。
```

## 通用执行规程（16 次课通用，单人独立完成）

1. **独立工作区**：每位学生在 WorkBuddy 中新建本课工作区，一次上传本包内全部素材；提示中声明「本课只能使用这些材料」。输出目录按 `L课次-个人-成果名-v版本` 命名。
2. **先计划、后动手**：先发「通用准备提示词」，要求 WorkBuddy 只输出目标理解、输入文件与版本、必须遵守的限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单；**此轮不写文件、不联网、不连接服务、不发布**。你本人逐项确认计划后，再让它一次完成一个工作包。
3. **独立复核**：需要第二视角时，在同一账号下**新开独立会话**扮演审校员，只提供原始材料与验收规则，**不把前一会话的结论透露给它**。同一会话既执行又自证，判为无效。
4. **逐条验收**：用文件字段、算式、测试输出、可见运行页面或独立审查会话作证。**WorkBuddy 说「已完成」不等于通过**；每步保留输入、产物/工具结果、检查结果与下一步。
5. **可观察留证**：保留可见的提示词、工具结果、文件差异、测试与运行结果；不要求、也不保存模型隐式思维链。
6. **安全边界**：练习包内全部为虚构数据与演示身份。不得上传真实学号、手机号、身份证、账号口令或正式密钥。若 WorkBuddy 请求改动超出任务范围、接触个人数据、访问未授权路径、调用外部服务或公开发布，**立即暂停并由你本人确认**；无授权则采用任务单中的「模拟替代」，并显式标注「模拟 / 未启用 / 未上线」，不得把文字草案说成已连接、已触发或已上线。
7. **错误处理**：保留错误版本与可观察记录，另存 `v0-failed`，不覆盖固定输入与测试预期；先找第一次偏离验收要求的位置，再修正、重跑、留下前后对比证据。
8. **提交**：按本任务单「提交清单」逐项勾选，未通过项、模拟项和未知项都要显式写明。成果物命名带课次、个人标识与版本号。

> 评分：每课评价要点合计 100 分。步骤分钟数相加等于本课任务时长；建议按分钟推进，最后留 8—10 分钟做独立复核与归档。
