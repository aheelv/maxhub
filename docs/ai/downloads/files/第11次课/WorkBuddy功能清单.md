# 第 11 次课｜WorkBuddy 功能覆盖清单

> 多智能体与AgentOps · 85 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 文件读取与数据核验 | 读取 survey.csv 等 6 份材料，输出计数与分母 | 数据检查表与原始回答 | ☐ |
| 多会话角色模拟 | 按资料员/分析员/审校员/主管顺序开独立会话 | 四个角色提示词与输出 | ☐ |
| 专家 / 专家团 | 最多选择一个专家或专家团并记录选择 | 专家选择与说明 | ☐ |
| 表格生成 | 输出拓扑对照表、回滚记录、指标表 | L11-*.csv 三张表 | ☐ |
| 文档整理与导出 | 把核验结果整理成一页决策简报 | 简报文件 | ☐ |
| 版本与留证 | 错误草稿另存 rejected/ 或 v0-failed | 回滚前后文件清单 | ☐ |

共 **6 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
