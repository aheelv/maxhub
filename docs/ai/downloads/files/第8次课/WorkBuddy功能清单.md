# 第 8 次课｜WorkBuddy 功能覆盖清单

> 智能体端到端与权限 · 80 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 智能体端到端任务 | 一次从需求到多文件产物的真实任务 | 产物文件 + 工具调用记录 | ☐ |
| 多会话隔离 | 纯对话 / 带工具 / 审校三个会话互不污染 | 三轮提示词与原始回答 | ☐ |
