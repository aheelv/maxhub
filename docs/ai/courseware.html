课件中心

16 次课，每套课件都与该次课的知识点逐一对应：讲清「来龙去脉 → 核心知识点 → 最新实践 → 真实数据 → 课堂练习 → 小结与关键术语」。每个概念、术语与机制都配具体示例——计算示例、正误对照、反例、流程示例、场景示例与输入输出示例轮换出现，示例中的公式、代码与算术均已核对。支持在线翻页、目录跳转与打印导出 PDF。

按课次浏览课件

点击任意课件进入播放页；播放页按 ← / → 翻页，按 O 切换目录，右上角可打印导出。

使用说明：课件内容随技术迭代持续更新（最近更新：2026 年 10 月）。若发现内容需要补充或修正，可在 个人中心 提交学习反馈。所有引用的数据与出处见 拓展资源 · 数据来源。
How to use

三种使用方式

课堂讲授

教师按课件顺序讲解，重点页配合板书与演示；每套课件的「课堂练习」页对应大纲中的实操环节。

课后复习

学生按目录跳转到不懂的知识点，配合 术语词典 查清概念，再回到课件看上下文。

打印 / 导出 PDF

在播放页点击「打印 / PDF」，浏览器会按「一页一张幻灯片」排版，可直接导出为 PDF 存档或打印讲义。
