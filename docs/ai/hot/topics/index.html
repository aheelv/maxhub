一、专题区是什么

专题区是《最热AI应用实践课》之下的第二层内容组织：5 节热点实践课各自独立、一节课产出一个成品；专题则由若干 90 分钟单元组成，围绕一条能力主线连续递进，共用同一个贯穿项目与同一套环境，学完可形成完整的方法体系与可运行系统。

维度热点实践课（5 节）专题（本区）
组织方式按技术应用热度排序的 5 个独立方向按能力体系组织的连续单元
单次时长90 分钟 / 节90 分钟 / 单元
成果一个可展示作品 + 100 分验收四单元累积成一套可运行系统 + 分单元验收
前置依赖各课互不依赖单元间递进，但每单元自带全部材料与兜底路径
扩展方式新增一节需补方向依据、素材与验收新增一个专题卡 + 一个目录

本页同时是专题区的「目录文件」：所有专题在此登记，预留位明确标注待开放，不指向不存在的页面。

三、扩展约定（新增专题的标准做法）

专题区采用「一个目录 + 一个导学页 + 若干单元页」的固定结构，所有页面共用 hot/assets/hot.css，导航与页脚由统一模板生成。

hot/
├─ index.html                   拓展课程主页（含专题区卡片）
├─ assets/hot.css               全分站共用样式
└─ topics/
   ├─ index.html                专题区索引（本页，专题登记表）
   └─ <专题标识>/
      ├─ index.html             专题导学页：体系地图 / 路线 / 环境 / 成果
      ├─ unit1.html … unitN.html 每单元 90 分钟全文
      └─ materials/             可选：代码与样例数据整包
  1. 在 hot/topics/index.html 的专题清单表追加一行，状态标为「已开放」，入口指向新目录。
  2. 在 hot/index.html 的 #topics 区复制一张 .topic-card，填写专题名、单元数与各单元入口；如需更多展示位，复制 .slot-card 即可。
  3. 新建 hot/topics/<专题标识>/，按统一模板放 index.html 与 unitN.html；每页导航含「拓展专题区」回链，页内目录采用 .toc。
  4. 资料包放该专题的 materials/，下载链接用相对路径；最后核对两门课程站点对应目录的文件集合与内容一致。
命名约定：目录用小写英文与连字符（如 enterprise-agent）；单元页用 unit1.html 递增；专题内链接一律相对路径，使其在 /maxhub/hot/ 与 /maxhub/ai/hot/ 两个部署位置都能直接工作。
