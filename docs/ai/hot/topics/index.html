拓展专题区

《最热AI应用实践课》之下的第二层内容组织：一个专题 = 一组连续递进的 90 分钟单元。

5 节热点实践课解决「一节课做出一个成品」；专题区解决「把一类能力看成一个整体」。这里不要求你做出系统，只要求你看懂全貌、说清关系。

专题 01 的新口径：给谁看、看什么、不看什么

本次调整只改变这一专题的研究口径，不改变主题范围，也不改动原有 5 节实践课。

概念

给谁看

管理学院大数据专业、计算机开发基础薄弱、近乎零开发经验的同学。全篇从「第一次听说这些名词」的角度组织，用管理场景和类比引入，不假设任何编程背景。

概念

看什么

企业级智能体开发当前所用的各类技术、核心概念、典型应用场景，以及它们之间的相互关系；最终形成一张能复述的全景认知地图。

概念

不看什么

不写代码、不搭环境、不交付系统、不讲开发教程。技术名词只要求「认得出、说得出用途、举得出场景」。

学完的检验标准：在相关岗位面试中，能就基础概念、技术用途与应用场景作出清晰表述；能画出「业务问题 → 用到哪些技术 → 有什么风险 → 哪些岗位负责」的一条线。
