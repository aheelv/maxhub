新增一个专题的四步

统一的卡片结构让扩展成本固定，页内导航、样式与下载通道自动复用。

  1. 在 hot/index.html 的「三、拓展专题区」清单里复制一张 .topic-card，改标题、标签与单元清单。
  2. 新建 hot/topics/<专题标识>/，放入 index.html 与各 unitN.html。
  3. 在本页专题清单表中追加一行，并把资料包放入该专题的 materials/。
  4. 按现有约定复用 hot.css 与 topics/assets/deck.css，无需改动主站其它页面。
约定：每个单元页保持「学习目标 → 核心知识 → 场景 → 环境 → 逐步开发 → 验收 → 排错」结构，并以 PPT 分页呈现；链接一律使用相对路径，便于同时部署在站点根与 /ai/ 子路径。
