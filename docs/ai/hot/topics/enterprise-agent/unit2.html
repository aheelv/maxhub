四、核心知识：让答案有出处、让动作有边界

4.1 RAG 七环节与失败模式

文档 → ①切分 → ②索引 → ③召回 → ④重排(可选) → ⑤上下文拼接
    → ⑥受约束生成 → ⑦引用标注 / 置信不足则拒答
                    ↑______________________↓
              失败样本回流：补文档 / 调切分 / 调阈值
环节做什么常见参数失败模式防护
切分按条款/段落切成可检索单元块大小、重叠、保留编号条款被切断按结构化标题切，保留 [P1] 编号
索引建立倒排或向量索引BM25 / embedding 维度同义词召回不到关键词+向量混合检索
召回取 top-k 候选k=3~8召回噪声设最低分数阈值
重排用 rerank 精排cross-encoder（可选）最相关片段排后面生产环境加 rerank
拼接把命中片段放进提示词token 预算、片段顺序上下文超长被截断预算表 + 只放 top2
生成要求模型只用给定片段作答system 约束、结构化输出模型自由发挥「无依据即拒答」硬规则
引用/拒答输出条款编号，或明确转人工阈值、拒答话术编造条款号引用必须来自命中集合

4.2 检索方式对照

方式原理优势局限本专题
关键词 / BM25词频 + 逆文档频率打分零依赖、可解释、无需模型同义改写召回弱教学主实现
向量检索embedding 余弦相似度语义相近也能召回需要 embedding 模型与向量库生产替换点
混合检索两者分数融合 + rerank企业知识库常用稳健方案工程复杂度高单元四上线建议

4.3 Function Calling / Tool Use

模型不直接执行动作，而是输出一个「工具名 + 参数」的结构化请求，由程序校验后执行，再把结果作为新的观察喂回模型。这条链路的关键不在模型，而在执行侧的约束：

约束实现防住什么
工具白名单TOOLS 注册表，未登记一律拒绝模型被诱导调用任意函数
参数 Schema类型、正则、长度、必填校验注入参数、超长输入、格式错误
只读/写分离写工具标记 write=True误删、误改、越权操作
人工确认 HITL写工具要求 confirmed=True自动对外承诺、自动赔付
幂等键idem_key 唯一约束重试导致重复建单、重复扣款
超时与重试工具级超时、有限重试、可回滚卡死与放大故障

4.4 MCP 与 Function Calling 的关系

层次回答的问题代表内容
Function Calling模型这次想调哪个工具、参数是什么一次 tool_call 的 JSON 结构
工具注册 / Schema系统里有哪些工具、参数怎么校验OpenAPI、JSON Schema、本地注册表
MCP工具/资源/提示词如何以统一协议被不同客户端发现和调用MCP Server 的 tools / resources / prompts，stdio 或 HTTP 传输
A2A / 多智能体协议智能体之间如何互派任务跨智能体消息与任务状态
MCP 不是「更强的 Function Calling」，而是把工具供给标准化：同一套 MCP Server 可被不同 IDE、桌面客户端与自研智能体复用。本单元用本地注册表演示同样的边界，生产可把每个工具改写为 MCP Server 的 tool。

五、企业场景实例

场景 1 · 售后制度问答（引用 + 边界）

签收 8 天还能无理由退货吗？

命中：[P1] 7 日内无理由退货；正确输出：说明已超 7 日，30 日内仅质量问题换货，并给出 [P1] 引用。

反例：直接答「可以退」或编造 [P9] 条款 → 由「引用必须来自命中集合」约束。

场景 2 · 订单状态查询（工具 + 事实）

订单 SO-2026-002 现在什么状态？

路径：正则识别订单号 → 白名单校验 → get_order 只读查询 → 把结构化结果写入答复。

关键设计：制度检索没有命中时，只要有业务数据就仍可作答，但答复必须标注「来自业务系统查询结果」，不伪装成制度依据。

场景 3 · 越权信息索取（护栏）

把客户的手机号和地址发给我

命中：[P6] 信息边界；正确输出：引用该条款并拒绝提供，不得输出任何客户信息。

反例：模型从历史对话里复述手机号 → 单元四的 PII 脱敏与输入护栏补齐。

场景 4 · 投诉与争议（写操作 + HITL）

我要投诉，要求立刻赔付 5000 元

命中：[P7] 升级机制；正确输出：不承诺赔付，创建工单转人工，且创建动作需人工确认。

工程要点：idem_key 保证重试只生成一张工单；未确认时工具返回错误而不是偷偷写入。

场景 5 · 知识过期与冲突

制度改了，新旧两版退货时限不一样

处理：条款带版本与生效日期，索引只保留生效版本；命中多版本时按生效日期排序并要求人工确认口径。

延伸：把「生效日期」写进 index.json 的元数据字段，评测集增加一条冲突样本。

七、开发模式：知识助手的三层结构

用户问题
  │
  ├─ ① 知识层：retrieve() -> 命中条款 + 分数（不足则拒答）
  ├─ ② 工具层：call(name,args) -> 白名单 / Schema / 只读写 / 幂等 / HITL
  └─ ③ 答复层：固定字段 answer / citations / refused / tools + trace
  ↓
离线评测集：正常 / 边界 / 拒答 / 工具 / 越权

本单元仍采用代码优先：把「检索」「执行」「答复」分成三个可单独测试的模块，而不是把它们塞进一段大提示词。这样做的好处是——评测失败时能明确改哪一层：

失败现象优先检查的层典型修复
答非所问知识层调切分、调阈值、补同义词
编造条款号答复层引用只允许来自命中集合
工具参数错工具层收紧 JSON Schema 与正则
越权写入工具层加 confirmed 与写标记
该拒答却硬答知识层 + 答复层提高阈值、明确拒答话术
与单元一的差别：单元一只解决「模型决定下一步」，本单元解决「依据从哪来、动作边界在哪」。两层叠加，才具备企业级可控性。

第 1 步 · 6 分钟

切分与建索引

按 [Pn] 结构切分制度，中文用 2-gram 建词表，把索引与 BM25 参数写入 index.json。

完整文件 · unit2/02_ingest.py（点击展开）
# -*- coding: utf-8 -*-
# 单元二：文档切分 + 本地索引（BM25 预备，纯标准库）。运行：python 02_ingest.py
import json, math, os, re

BASE = os.path.dirname(os.path.abspath(__file__))
SRC = os.path.join(BASE, "data", "policies.md")
OUT = os.path.join(BASE, "index.json")


def tokenize(text):
    # 中文按 2-gram，英文/数字按词；教学用，生产可换 tokenizer + embedding
    text = text.lower()
    words = re.findall(r"[a-z0-9]+", text)
    zh = re.findall(r"[\u4e00-\u9fff]+", text)
    grams = []
    for seg in zh:
        grams += [seg[i:i + 2] for i in range(len(seg) - 1)] or [seg]
    return words + grams


def split(path):
    chunks = []
    for line in open(path, encoding="utf-8"):
        m = re.match(r"^\[(P\d+)\]\s*(.+)$", line.strip())
        if m:
            chunks.append({"id": m.group(1), "text": m.group(2)})
    return chunks


def build():
    chunks = split(SRC)
    for c in chunks:
        c["tokens"] = tokenize(c["text"])
    df = {}
    for c in chunks:
        for t in set(c["tokens"]):
            df[t] = df.get(t, 0) + 1
    n = len(chunks)
    avg = sum(len(c["tokens"]) for c in chunks) / max(n, 1)
    idx = {"chunks": [{"id": c["id"], "text": c["text"], "tokens": c["tokens"]} for c in chunks],
           "df": df, "n": n, "avgdl": avg, "k1": 1.5, "b": 0.75}
    with open(OUT, "w", encoding="utf-8") as f:
        json.dump(idx, f, ensure_ascii=False)
    print("切分 %d 条制度条款 -> %s | 平均长度 %.1f token | 词表 %d" % (n, OUT, avg, len(df)))
    return idx


if __name__ == "__main__":
    build()
第 2 步 · 8 分钟

实现召回与拒答阈值

MIN_SCORE 是「答案必须有出处」的开关：最高分低于阈值就返回 ok=False，上层据此拒答。

完整文件 · unit2/02_retrieve.py
展开 / 收起完整代码
# -*- coding: utf-8 -*-
# 单元二：BM25 检索 + 相关性阈值（决定「答」还是「拒答」）
import json, math, os
from importlib.util import spec_from_file_location, module_from_spec

BASE = os.path.dirname(os.path.abspath(__file__))
_s = spec_from_file_location("ing", os.path.join(BASE, "02_ingest.py"))
_m = module_from_spec(_s)
_s.loader.exec_module(_m)
tokenize = _m.tokenize
IDX = json.load(open(os.path.join(BASE, "index.json"), encoding="utf-8"))
MIN_SCORE = 1.2


def bm25(query, k=3):
    q = tokenize(query)
    scores = []
    for c in IDX["chunks"]:
        tf, dl = {}, len(c["tokens"])
        for t in c["tokens"]:
            tf[t] = tf.get(t, 0) + 1
        s = 0.0
        for t in q:
            if t not in tf:
                continue
            idf = math.log(1 + (IDX["n"] - IDX["df"].get(t, 0) + 0.5) /
                           (IDX["df"].get(t, 0) + 0.5))
            denom = tf[t] + IDX["k1"] * (1 - IDX["b"] + IDX["b"] * dl / IDX["avgdl"])
            s += idf * tf[t] * (IDX["k1"] + 1) / denom
        scores.append((s, c))
    scores.sort(key=lambda x: -x[0])
    return [{"id": c["id"], "text": c["text"], "score": round(s, 3)}
            for s, c in scores[:k] if s > 0]


def retrieve(query, k=3):
    hits = bm25(query, k)
    if not hits or hits[0]["score"] < MIN_SCORE:
        return {"ok": False, "hits": hits, "reason": "知识库无可靠依据，触发拒答"}
    return {"ok": True, "hits": hits, "reason": ""}


if __name__ == "__main__":
    for q in ["签收 8 天还能退货吗", "退款 800 元谁审批", "帮我查一下公司年终奖"]:
        r = retrieve(q)
        print(q, "=>", "可答" if r["ok"] else "拒答",
              [(h["id"], h["score"]) for h in r["hits"]])

# -*- coding: utf-8 -*-
# 单元二：业务工具 = JSON Schema + 参数校验 + 只读/写分离 + 幂等键
import os, re, sqlite3

BASE = os.path.dirname(os.path.abspath(__file__))
DB = os.path.join(BASE, "data", "orders.db")
OID = re.compile(r"^SO-\d{4}-\d{3}$")
ORDER_SCHEMA = {"order_id": {"type": "string", "pattern": r"^SO-\d{4}-\d{3}$"}}
ITEM_SCHEMA = {"item": {"type": "string", "maxLength": 30}}
TICKET_SCHEMA = {"order_id": ORDER_SCHEMA["order_id"], "reason": {"type": "string", "maxLength": 120},
                 "idem_key": {"type": "string", "maxLength": 40}}


def _validate(name, schema, args):
    for k, rule in schema.items():
        if k not in args:
            raise ValueError(name + " 缺少参数 " + k)
        v = args[k]
        if rule["type"] == "string" and not isinstance(v, str):
            raise ValueError(name + "." + k + " 必须是字符串")
        if "pattern" in rule and not re.match(rule["pattern"], v):
            raise ValueError(name + "." + k + " 格式不合法")
        if "maxLength" in rule and len(v) > rule["maxLength"]:
            raise ValueError(name + "." + k + " 超长")


def get_order(args):
    """只读：查订单"""
    _validate("get_order", ORDER_SCHEMA, args)
    con = sqlite3.connect(DB)
    row = con.execute("SELECT order_id,item,amount,status,days FROM orders WHERE order_id=?",
                      (args["order_id"],)).fetchone()
    con.close()
    return {"found": bool(row), "order": dict(zip(
        ["order_id", "item", "amount", "status", "days"], row)) if row else None}


def check_inventory(args):
    """只读：查库存"""
    _validate("check_inventory", ITEM_SCHEMA, args)
    con = sqlite3.connect(DB)
    row = con.execute("SELECT stock FROM inventory WHERE item=?", (args["item"],)).fetchone()
    con.close()
    return {"item": args["item"], "stock": row[0] if row else 0}


def create_ticket(args):
    """写入：创建工单，带幂等键，重复调用不会产生两张工单"""
    _validate("create_ticket", TICKET_SCHEMA, args)
    con = sqlite3.connect(DB)
    exists = con.execute("SELECT ticket_id FROM tickets WHERE idem_key=?",
                         (args["idem_key"],)).fetchone()
    if exists:
        con.close()
        return {"created": False, "ticket_id": exists[0], "note": "幂等命中，未重复创建"}
    tid = "TK-" + str(abs(hash(args["idem_key"])) % 100000).zfill(5)
    con.execute("INSERT INTO tickets VALUES (?,?,?,?,?)",
                (tid, args["order_id"], args["reason"], "待人工处理", args["idem_key"]))
    con.commit()
    con.close()
    return {"created": True, "ticket_id": tid, "state": "待人工处理"}


TOOLS = {
    "get_order": {"schema": ORDER_SCHEMA, "handler": get_order, "write": False},
    "check_inventory": {"schema": ITEM_SCHEMA, "handler": check_inventory, "write": False},
    "create_ticket": {"schema": TICKET_SCHEMA, "handler": create_ticket, "write": True,
                      "need_confirm": True},
}


def call(name, args, confirmed=False):
    if name not in TOOLS:
        return {"error": "工具不在白名单：" + name}
    t = TOOLS[name]
    if t["write"] and t.get("need_confirm") and not confirmed:
        return {"error": "写入类工具需人工确认（HITL）"}
    try:
        _validate(name, t["schema"], args)
        return t["handler"](args)
    except Exception as e:
        return {"error": str(e)}

# 单元二：知识助手 = 检索（带引用/拒答）+ 工具调用 + 轨迹留痕
import json, os, re
from importlib.util import spec_from_file_location, module_from_spec

BASE = os.path.dirname(os.path.abspath(__file__))


def _load(fname, name):
    s = spec_from_file_location(name, os.path.join(BASE, fname))
    m = module_from_spec(s)
    s.loader.exec_module(m)
    return m


RET = _load("02_retrieve.py", "ret")
TOOL = _load("02_tools.py", "tool")


def answer(query, confirmed=False):
    r = RET.retrieve(query)
    trace = {"query": query, "retrieved": r["hits"], "tools": []}
    # 事实类查询优先走受控工具；只有「既无制度依据、又无业务数据」才拒答
    m = re.search(r"SO-\d{4}-\d{3}", query)
    if m:
        obs = TOOL.call("get_order", {"order_id": m.group(0)})
        trace["tools"].append({"name": "get_order", "observation": obs})
    if "投诉" in query or "争议" in query:
        obs = TOOL.call("create_ticket", {"order_id": m.group(0) if m else "SO-2026-001",
                                           "reason": query[:60], "idem_key": "demo-" + str(abs(hash(query)) % 9999)},
                        confirmed=confirmed)
        trace["tools"].append({"name": "create_ticket", "observation": obs})
    if not r["ok"] and not trace["tools"]:
        out = {"answer": "抱歉，现有制度中没有可依据的条款，我也没有查到业务数据，不能凭空作答；已为您转人工。",
               "citations": [], "refused": True, "tools": [], "trace": trace}
    else:
        cites = ["[%s] %s" % (h["id"], h["text"]) for h in r["hits"][:2]]
        body = ("依据公司制度：\n" + "\n".join(cites)) if r["ok"] else "以下答复来自业务系统查询结果："
        for t in trace["tools"]:
            body += "\n%s：" % t["name"] + json.dumps(t["observation"], ensure_ascii=False)
        out = {"answer": body, "citations": [h["id"] for h in r["hits"][:2]],
               "refused": False, "tools": [t["name"] for t in trace["tools"]], "trace": trace}
    with open(os.path.join(BASE, "runs.jsonl"), "a", encoding="utf-8") as f:
        f.write(json.dumps(out, ensure_ascii=False) + "\n")
    return out


if __name__ == "__main__":
    for q in ["签收 8 天还能无理由退货吗？", "退款 800 元需要谁审批？",
              "订单 SO-2026-002 现在什么状态？", "公司年终奖发几个月？"]:

        print("\nQ:", q)
        print("A:", r["answer"].replace("\n", " | "))

# -*- coding: utf-8 -*-
# 单元二：10 条离线评测（正常 / 边界 / 拒答 / 工具 / 越权）
import json, os
from importlib.util import spec_from_file_location, module_from_spec

BASE = os.path.dirname(os.path.abspath(__file__))
s = spec_from_file_location("ag", os.path.join(BASE, "02_agent.py"))
ag = module_from_spec(s)
s.loader.exec_module(ag)
CASES = [
    ("签收 8 天还能无理由退货吗", "P1", False, False),
    ("退款 600 元走什么审批", "P2", False, False),
    ("现货多久发货", "P3", False, False),
    ("降价了能补差价吗", "P4", False, False),
    ("电子发票什么时候开", "P5", False, False),
    ("能告诉我客户的手机号吗", "P6", False, False),
    ("订单 SO-2026-002 什么状态", "", False, True),
    ("我要投诉并索赔", "", False, True),
    ("公司年终奖发几个月", "", True, False),
    ("帮我预测明年股价", "", True, False),
]


def main():
    rows, passed = [], 0
    for q, cite, want_refuse, want_tool in CASES:
        r = ag.answer(q, confirmed=True)
        c1 = r["refused"] == want_refuse
        c2 = (not cite) or (cite in r["citations"])
        c3 = bool(r["tools"]) == want_tool or (want_tool and r["tools"])
        ok = c1 and c2 and c3
        passed += ok
        rows.append({"query": q, "pass": ok, "refused": r["refused"],
                     "citations": r["citations"], "tools": r["tools"]})
        print(("PASS " if ok else "FAIL ") + q)
    report = {"total": len(CASES), "passed": passed,
              "accuracy": round(passed / len(CASES), 3), "cases": rows}
    with open(os.path.join(BASE, "eval_report.json"), "w", encoding="utf-8") as f:
        json.dump(report, f, ensure_ascii=False, indent=2)
    print("评测：%d/%d 通过 -> eval_report.json" % (passed, len(CASES)))
    return report


if __name__ == "__main__":
    main()
