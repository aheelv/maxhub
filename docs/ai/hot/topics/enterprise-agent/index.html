一、为什么单列这个专题

「会用 AI 工具」与「能把智能体做成企业可用的系统」是两种能力。前者关注一次对话的产物，后者必须回答六个工程问题：用什么技术、系统怎么分层、在什么环境里跑、采用哪种开发范式、按什么流程交付、哪些场景值得做。本专题以 4 个 90 分钟单元把这条链路一次走完，既讲清主流技术全景，也给出每一步可复制、可运行、可验收的实践。

六、自学常见问题

没有大模型 API Key，能完成全部实践吗？

能。所有代码默认走内置 MockLLM，它按规则返回「调用哪个工具、参数是什么」，因此可以完整演示感知—决策—执行—观察—终止的循环、RAG 引用、多智能体协同与评测。有 Key 时把 LLM_BACKEND 改成 api 即可对照真实模型行为。

要不要先学 LangChain / LangGraph？

不需要。专题先用标准库把原理跑通，再在每单元标出「生产替换点」。先理解状态、工具、终止条件与护栏，再学框架会更快；反之直接套框架容易把调试问题误认为模型问题。

可以只学某一个单元吗？

可以，但建议按序。每个单元都自带「前置检查」与完整材料，跳读时需要按单元开头的最小准备命令补齐目录与样例数据。

专题与 5 节热点实践课的关系？

并行不冲突。第 3 课的问答助手与第 5 课的编程小应用是很好的热身；本专题把它们扩展为体系化工程能力。原有 5 课全文、素材包与验收标准全部保留。
