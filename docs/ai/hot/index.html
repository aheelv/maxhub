按当前 AI 应用领域技术应用热度由高到低，选取 5 个可在一节 90 分钟实践课内独立完成、并有明确成品的方向；每节配齐素材、工具环境、逐步操作指导、从输入到成品的一站式流程与 100 分验收标准。以 WorkBuddy 为主要工具。

一、当前 AI 应用热度前 5 实践方向

按「产业产出与增速 / 用户侧渗透率 / 技术与工具生态热度 / 可交付作品密度」四维综合研判，由高到低排序。这是面向实践课的教学研判排序，不是官方榜单；四维依据、13 条公开来源（S1—S11 及 S1b、S9b 补充条目）与「仅按 CNNIC 用户渗透率」的单指标对照口径，详见全套资料包中的 00_热度排序与依据.md。

名次实践方向本节做成什么用户侧证据产业侧证据技术侧证据来源课程
第 1 位AI 短剧 / 微短剧一站式制作从题材与脚本出发，完成人物设定、分镜、分镜图、字幕与可播放的分镜预览页，形成一部可展示的微短剧制作包。高：处理图片/视频 47.8%（S1/S1b）很高：2026 Q1 AI 微短剧约 12.2 万部 / 全行业 12.8 万部，占比 >95%（S2）；上半年新上线 22.19 万部、全年市场预计 400 亿元、同比 +138%、从业者超 50 万（S4）很高：AI 短剧 / AI 漫剧为 2026-09 搜索热词；剧本—分镜—角色一致性—渲染—剪辑形成工业化闭环（S10/S11/S5）S1, S1b, S2, S3, S4, S5, S10, S11进入第 1 课 →
第 2 位AI 小说 / 网文与 IP 设定集创作从世界观与人物小传出发，产出三章连贯短篇、连续性校对表、术语/人物索引与带封面的电子书阅读页。较高：文本处理 37.6%（S1/S1b）高：网络文学市场规模突破 3000 亿元、AI 辅助创作作者 43.7%（S6）；AI 辅助写小说创作者规模同比 +217%、63% 全职网文作者使用 AI（S7，行业报道口径）较高：长上下文、风格控制、连续性检查与设定集管理成为通用工作流；长文本属于大模型基础能力S1, S1b, S6, S7进入第 2 课 →
第 3 位AI 智能问答助手与课程知识库搭建把原始 FAQ 语料清洗为结构化知识条目，搭建可运行的问答页与拒答边界，并用标准评测集给出准确率报告。很高：智能问答 76.0%，为全部用途中最高（S1/S1b）；AI 原生 APP 月活 4.99 亿（S8）较高：AI 综合助手使用次数同比增长超 100%（S1）；但多为平台型通用产品，独立可交付项目密度低于内容创作高：知识库、检索增强、拒答与评测是当前助手类应用的标准环节S1, S1b, S8进入第 3 课 →
第 4 位AI 办公文档 · PPT · 数据报告一体化产出把会议原始记录与经营数据清洗为口径一致的报告、演示文稿、数据表与一页式摘要，形成一套可复用办公产物。中高：工作总结 / 会议纪要 / PPT 32.5%（S1/S1b）较高：AI 效率办公使用次数同比增长超 100%（S1）；GitHub Copilot 使 PR 数量提升约 26%（S9，效率类证据）中高：文档、表格、演示与图表生成能力已高度工具化，创新点在口径核对与一致性S1, S1b, S9进入第 4 课 →
第 5 位AI 编程与智能体小应用搭建用自然语言需求驱动 WorkBuddy 生成一个可运行的单文件小工具，完成测试用例、缺陷修复与交付说明。中：大众渗透率低于前四类，主要集中于开发者与进阶用户（S10 热词观察）高但面向专业人群：组织 AI 采用率 88%（S9）；Gartner 预测 2026 年底 40% 企业应用嵌入任务型智能体（站点技术趋势页既有引用）很高：真实计算机任务成功率由约 12% 升至约 66%；AI 编程 / AI Agent / 编排层为持续热词（S9/S10）S9, S9b, S10进入第 5 课 →
口径说明：CNNIC《生成式人工智能应用发展报告（2026）》中智能问答以 76.0% 居单项用途首位，但它是通用「即用即走」能力；短剧在产业产出（AI 微短剧占新上线 >95%）、全链路技术环节与作品可交付密度上更高，故综合排序第 1。若仅按用户渗透率单指标，顺序为「问答 > 图片视频 > 文本 > 办公 > 编程/智能体」。

五、WorkBuddy 能力基线

5 节课的每一个操作步骤都映射到下表中一条本环境实际可用的能力；未开通能力一律给出等价替代路径，不阻塞交付。

能力编号能力说明
WB-CHAT对话与长文写作在会话中生成/改写剧本、小说、报告、提示词；支持长文本与多轮修订。
WB-FILE本地文件读写创建、修改、读取 .md/.csv/.json/.srt/.html/.py 等文件，并可批量组织目录。
WB-CMD命令执行与数据处理运行 Python/Node 等命令做数据清洗、校验、ZIP 打包、本地静态服务启动与 HTTP 自检。
WB-WEB联网检索与网页读取检索并核对公开资料、来源 URL 与发布日期。
WB-IMAGE图像生成（文生图 / 图生图）按提示词生成分镜图、封面图、海报；可指定尺寸与风格。按平台计费，约 5–10 积分/张。
WB-OFFICEOffice 文档生成生成 / 编辑 Word、Excel、PPT 文件与对应阅读版。
WB-HTML网页与应用构建、预览生成可在浏览器直接运行的 HTML/CSS/JS 页面与小工具，并在预览面板打开。
WB-VIDEO视频生成（可选能力）文生视频 / 图生视频，生成短片段。属可选路径；未开通时课程成品以分镜预览页交付，不阻塞流程。
