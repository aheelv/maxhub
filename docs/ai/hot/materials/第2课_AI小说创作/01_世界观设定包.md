# 世界观设定包 · 账本城（课堂虚构）

## 基本设定

账本城是一座把「每一次选择」都记进公共账册的架空校园城。城中居民不使用货币，只使用「条目」：每写下一条，就必须划掉另一条。城里有三条街（东街、纸街、钟楼街）、一座旧钟楼、一间只在周五开放的寄存处。

## 硬设定（H1—H5）

| 编号 | 规则 |
| --- | --- |
| H1 | 任何人每天只能在公共账册上写一条新条目，写第二条时第一条会自动消失。 |
| H2 | 寄存处只在周五傍晚开放，其余时间门是锁着的，任何人都不能进入。 |
| H3 | 旧钟楼的钟只在有人做出「不可撤回的选择」时敲响，其他时候永远静止。 |
| H4 | 划掉的条目无法恢复，但可以在别人的账册里被重新抄写一次。 |
| H5 | 城中不允许出现「购买」「付款」「价格」这类与货币有关的说法。 |

## 时间线

| 时间点 | 事件 |
| --- | --- |
| 周一清晨 | 公共账册换上新的一页 |
| 周二下午 | 纸街的抄写员开始整理上周条目 |
| 周三上午 | 钟楼无故被擦拭一遍，但钟没有响 |
| 周四傍晚 | 寄存处门口第一次出现排队的人 |
| 周五傍晚 | 寄存处开放，钟楼敲响一次 |
| 周六清晨 | 公共账册被收进档案柜 |

## 场所

| 场所 | 特征 |
| --- | --- |
| 东街 | 长桌连成一排，人们在这里写条目 |
| 纸街 | 抄写员聚集，墙上是层层旧纸 |
| 钟楼街 | 安静，地面有钟摆投下的长影 |
| 寄存处 | 木门、小窗、只在周五开 |
| 旧钟楼 | 指针停在某个位置，无人知道是谁停的 |

## 本世界不可能发生的事（负面约束）

1. 任何人用钱买东西或讨论价格。
2. 任何人把已经划掉的条目在自己账册里恢复。
3. 钟在没有「不可撤回的选择」时自己敲响。
