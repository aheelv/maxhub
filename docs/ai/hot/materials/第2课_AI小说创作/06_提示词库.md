# 第 2 课提示词库 · 可整段复制

## P1 风格基线
读取 04_风格样章.md，归纳：人称、时态、平均句长区间、对话占比、段落长度、常用意象、≥5 个禁用词、2 条硬规则。只归纳不改写。

## P2 设定集
读取 01_世界观设定包.md，整理 H1—H5（含检查方法）、地理表、≥5 行时间线、3 条负面约束。不得新增规则；信息不足标「待补充」。

## P3 人物小传
读取 02_人物小传模板.csv 与设定集，为 4 人补写动机/秘密/语言习惯/随身道具/硬设定关联；生成 4×4 关系矩阵。不得新增第 5 位具名人物。

## P4 三章大纲
按 03_章节大纲模板.csv 写 9 场景，第 1 章埋 F1/F2，第 3 章必须回收；每场景给出结果状态（人物位置与道具）。

## P5 逐章正文（把 {N} 换成章号）
写第 {N} 章：遵循 00_风格基线.md；不得违反 H1—H5 与 3 条负面约束；只用 4 人；严格按大纲第 {N} 章 3 场景展开；不少于 800 字、对话 ≥6 处；设定用行动体现不靠旁白；章末附状态登记表与实际字数。

## P6 连续性校对
按 05_连续性检查表.csv 六类逐条核验三章正文，输出问题清单 CSV（编号/类别/章号/原句摘录/违反规则/修订建议/是否已修订），至少覆盖 6 个指定具体问题；无问题的项也输出「通过」行。确认后实际修订正文。

## P7 索引与阅读版
从正文抽取 人物/地点/道具/术语 生成 08_索引.json（name/category/first_chapter/gloss/related），related 必须命中 items；生成单文件 11_阅读版.html（目录/章节切换/索引检索/封面相对路径/缺图 CSS 封面）。

## P8 封面
按 07_封面提示词.md 生成封面；不可用时用纯 CSS 绘制同构图封面并标注「图像生成未启用」。

## P9 自检
对照 08_验收量表.csv 打分；用脚本统计三章字数、CSV 行列数、JSON 可解析；生成制作说明（未启用能力如实标注）；打包 ZIP 并校验。
