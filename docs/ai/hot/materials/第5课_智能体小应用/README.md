# 第 5 课素材包 · AI 编程与智能体小应用

需求、报名数据与测试用例均为**课堂虚构内容**，学号为演示格式，不对应任何真实学生。

| 文件 | 用途 |
| --- | --- |
| 01_需求说明书.md | 含 3 处故意模糊表述的原始需求 |
| 02_报名样例数据.csv | 30 行含重复、缺字段、非法学号与超容量的数据 |
| 03_验收测试用例.csv | 12 个用例（正常/边界/异常） |
| 04_界面草图说明.md | 六区界面文字草图 |
| 05_提示词库.md | 7 类可复制提示词 |
| 06_README模板.md | 交付说明模板 |
| 07_验收量表.csv | 100 分量规机器可读版 |

核心纪律：需求先冻结为 R1—R6 再写程序；测试结论必须来自实际运行。
