# 第 5 课提示词库 · 可整段复制

## P1 需求澄清
读取 01_需求说明书.md 与 02_报名样例数据.csv，列出 ≥3 处无法直接编码的模糊表述（原文/原因/建议规则/关联用例号），建议规则标「待确认」；清点 8 份素材。

## P2 验收口径
把待确认规则冻结为 R1—R6（去重键与保留策略、必填字段、学号格式、容量上限与超额处理、先后判定依据、输出字段与排序），每条须可写成 if 判断并关联用例号；不得修改测试用例。

## P3 规则链
生成 03_规则链.json：mode=local-deterministic，四段（感知/判断/执行/校验），每 step 含 id/desc/rule_ref/input/output/on_error；写 04_规则链说明.md，明确「本地确定性，不连接外部平台」及其与真实智能体平台的三点区别。

## P4 生成工具
生成单文件 05_报名统计工具.html：六区界面、四段状态、六个统计卡、结果表、错误行明细、导出 CSV；CSV 解析支持引号字段与 BOM；所有判断可追溯到 R 编号；零依赖零网络；中文 UTF-8；无控制台报错。

## P5 测试
对 03_验收测试用例.csv 的 12 个用例实跑（可抽取核心逻辑为脚本，规则与网页一致），输出 06_测试记录.csv（用例号/类型/输入摘要/期望/实际/PASS或FAIL/失败原因/关联规则），并分三类统计通过率。

## P6 修复
据 FAIL 生成 08_缺陷记录.csv，实际修改网页逻辑后全量回归，输出 09_回归结果.csv 与修复前后对比表。禁止硬编码期望输出；新增 FAIL 必须记录并处理。

## P7 文档与核验
按 06_README模板.md 生成 10_README.md（六节、已知限制 ≥3 条、未启用能力逐项标注）与 11_制作说明.md；对照 07_验收量表.csv 打分；脚本校验 JSON 与 CSV 行数；打包 ZIP 并验证解压后工具页可独立打开。
