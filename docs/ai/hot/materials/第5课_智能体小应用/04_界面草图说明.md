# 界面草图说明（文字版）

```
┌──────────────────────────────────────────────┐
│ ① 输入区                                      │
│  [选择 CSV 文件]  [载入示例数据]  [开始处理]   │
│  ┌────────────────────────────────────────┐  │
│  │ 大文本粘贴框（可直接粘贴 CSV 内容）      │  │
│  └────────────────────────────────────────┘  │
├──────────────────────────────────────────────┤
│ ② 规则链状态区：感知 → 判断 → 执行 → 校验      │
│  每段显示 状态图标 / 处理行数 / 关联规则编号    │
├──────────────────────────────────────────────┤
│ ③ 统计卡（6 个）：总行数 有效 重复 缺字段      │
│                    格式错 超容量               │
├──────────────────────────────────────────────┤
│ ④ 结果表：按报名时间升序，列出有效名单字段      │
├──────────────────────────────────────────────┤
│ ⑤ 错误行明细：行号 / 错误类型 / 原始行内容      │
├──────────────────────────────────────────────┤
│ ⑥ [导出结果 CSV]   底部：本工具在浏览器本地运行  │
└──────────────────────────────────────────────┘
```

样式：浅色背景、卡片圆角、状态用颜色+文字双重标识（不只用颜色）、移动端纵向堆叠。
交互：点击「开始处理」后四段状态依次点亮；出错时对应段显示红色并给出行号。
