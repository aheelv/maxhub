# 站点地图 · 栏目层级 · 导航设计 · 迁移映射

> 文档性质：信息架构交付物 ①
> 机器可读真值源：`course-template/model/sitemap.json`
> 构建产物：`course-template/dist/sitemap.json`（215 条具体 URL）、`dist/sitemap.xml`、`dist/nav.json`

---

## 一、组织原则

### 1.1 单门课程为根

站点实例 = 一门课程的一次开课轮次。全站所有内容实例的 `course_id` 恒为 `AI-TOOLS-APPLY`。课程题目《人工智能工具应用实践》是贯穿各栏目的主线：每章标题、导入、案例与实践任务均回答"用最新 AI 工具解决哪一类真实问题"。

### 1.2 课次为唯一组织轴

| 内容类型 | 对齐方式 | 关联谓词 |
| --- | --- | --- |
| 教材章节 `TXT-{nn}` | `session_no = nn` | `aligned_with → S{nn}` |
| 网页课件 `DECK-{nn}` | 同上 | 同上 |
| PPTX 文件 `PPT-{nn}` | 同上 | 同上 |
| 教案 `PLAN-{nn}` | 同上 | 同上 |
| 大纲单元 `SYL-{nn}` | 同上 | 同上 |
| 日历条目 `CAL-{nn}` | 同上 | `scheduled_as` |
| 习题 `EX-{nn}` | 同上 | `aligned_with` + `assesses → 知识点` |
| 实践包 `KIT-{nn}` | 同上 | `aligned_with` + `uses → 素材` |

课次本身挂到模块：`S{nn} —belongs_to→ M{m}`。知识点由课次 `covers`，术语与案例由知识点 `defines / illustrates` 反向挂接。

### 1.3 三种视图，同一份数据

- **课次视图**（默认、线性）：`/sessions/` → 课次聚合页，服务"这周学什么"。
- **知识视图**（网状）：`/knowledge/` → 模块 / 知识点 / 术语，服务"这个概念在哪讲过"。
- **任务视图**（能力）：`/exercises/` + `/practice/`，服务"我要交什么、用什么做"。

三个视图不做三套内容，均由 `content-manifest.json` + `graph.json` 渲染。

## 二、栏目层级总表

| 层级 | 名称 | 作用 | 进入方式 |
| --- | --- | --- | --- |
| L0 | 课程层 | 课程定位、制度性信息、全站入口 | 主导航「课程总览」等一级项 |
| L1 | 课次主轴层 | 16 个课次聚合页，教与学的统一入口 | 主导航「课次主轴」 |
| L2 | 内容实体层 | 教材章节、课件、教案、习题、实践包的详情与播放页 | 课次聚合页的六大内容标签 |
| L3 | 知识与案例层 | 知识图谱、模块、知识点、术语、案例、趋势 | 主导航「知识图谱」「案例与资源」 |
| L4 | 系统层 | 素材原件、结构化数据出口、检索索引、站点地图、404 | 不进主导航 |

**深度约束**：主导航不超过 2 层；任何内容自首页起 3 次点击内可达；课次聚合页的深度为 1，其六个内容标签深度为 2。

## 四、URL 规范

| 规则 | 说明 |
| --- | --- |
| 目录式 | 一律 `/栏目/标识/`，结尾斜杠；不再使用 `lecture.html?n=8` 这类查询参数式地址 |
| 字符集 | URL 仅用小写 ASCII、数字、连字符；中文只出现在标题与文件名，不进入路径 |
| 课次标识 | 两位数字 `01`—`16`，与内容 ID `S01`—`S16` 一致 |
| 知识点标识 | 知识点 ID 小写，如 `KP-M1-01 → /knowledge/points/kp-m1-01/` |
| 案例标识 | `CASE-01 → /cases/case-01/` |
| 锚点 | 大纲 `#s{nn}`、日历 `#w{nn}`、术语 `#{anchor}`，锚点由稳定 ID 生成，不用序号 |
| 下载 | 统一走 `/downloads/`，响应头强制 `Content-Disposition: attachment`；中文文件名以 RFC 5987 编码，与规范 URL 解耦 |
| 稳定 ID | 内容 ID 一经发布不得变更；改名只改 `title` 与 `slug`，旧 URL 做 301 |

## 五、导航设计

### 5.1 全局主导航（7 项，含二级）

| 一级 | 二级 | 指向 |
| --- | --- | --- |
| 课程总览 | 课程介绍 / 教学大纲 / 教学日历 / 考核方式 | `/about/` `/syllabus/` `/calendar/` `/policies/` |
| 课次主轴 | （16 课次下拉，按模块分组） | `/sessions/` |
| 教材 | （16 章下拉） | `/textbook/` |
| 课件 | （按模块筛选） | `/courseware/` |
| 习题与实践 | 综合任务单 / 资源包下载 | `/exercises/` `/downloads/` |
| 知识图谱 | 知识模块 / 知识点 / 术语词典 | `/knowledge/modules/` `/knowledge/points/` `/knowledge/terms/` |
| 案例与资源 | 案例库 / 技术趋势 / 课程通知 / 前往超星学习通 | `/cases/` `/trends/` `/announcements/` 外链 |

主导航 7 项是模板上限（`course.config.schema.json` 中 `maxItems: 7`），文案、顺序与二级项均可按课程配置。

### 5.2 面包屑

固定为：**课程 › 模块 › 课次 › 内容类型 › 内容实例**，逐级可点。例：

```
人工智能工具应用实践 › 模块三 · 智能体技术 › 第 08 次课 › 教材 › 第 8 章 智能体原理与 MCP 协议
```

### 5.3 课次上下文导航（本次新增的核心组件）

每个课次聚合页固定包含：

1. **课次头部**：课次号、模块徽章、标题、学时、学习目标摘要、上一课／下一课。
2. **六大内容标签**：教材、课件、教案（教师可见）、习题、实践包、知识点。标签由 `content-manifest.json` 按 `session_no` 与 `type` 自动渲染，不手工维护链接。
3. **关联知识卡片**：本课覆盖的 86 个知识点中的对应子集，点击进入知识点详情。
4. **案例与术语**：由 `illustrates` / `defines` 反查生成。
5. **交付物与截止**：由 `calendar-entry` 与 `exercise.deliverables` 生成，日期为空时显示「待补充（以教务校历为准）」。

### 5.4 页脚与辅助导航

页脚固定：站点地图、对接与数据说明、课程团队、公开站点入口。另提供全站检索（基于 `search-index.json`）、按模块筛选、按标签筛选。

### 5.5 三条贯通路径

| 路径 | 入口 | 组织方式 | 适用情境 |
| --- | --- | --- | --- |
| 线性教学路径 | `/sessions/` | 模块 → 课次 → 内容 | 跟课学习、课前预习 |
| 知识检索路径 | `/knowledge/` | 模块 → 知识点 → 关联资源/题目 | 查漏补缺、概念回溯 |
| 能力达成路径 | `/exercises/` | 任务 → 步骤 → 成果物 → 量规 | 完成作业、准备答辩 |

三条路径在课次聚合页汇合，避免学生在不同栏目间迷路。

## 七、落地顺序与验收标准

| 阶段 | 动作 | 验收标准 |
| --- | --- | --- |
| 1 · 数据层 | 采用 `content-manifest.json` + `graph.json`；不改现网页面 | `validate.py` 零错误；371 实例文件引用全部可达 |
| 2 · 去重 | 下线账号/选课/反馈/统计/QR 与个人中心；相关入口改跳转超星 | 静态产物中无 `server.js`、`db.json`、登录与选课入口 |
| 3 · 课次主轴 | 新建 `/sessions/` 与 16 个课次聚合页 | 每课六大内容标签齐全；上一课/下一课正确；3 次点击可达 |
| 4 · 内容接入 | 教材 16 章、教案 16 份、日历 16 周、习题 16 题、实践包 16 套接入 | 每类内容均有独立 URL 与元数据；A 类截图来源可见 |
| 5 · 知识层 | 知识点 86、术语 103、案例 8 接入图谱 | 知识点详情可反查资源与题目；前置/后置关系标注「待补充」 |
| 6 · 导航统一 | 主导航 7 项、面包屑、检索、站点地图、页脚 | 旧 15 页全部有迁移目标；无孤儿页面与死链 |
| 7 · 对接 | 按 `03_超星学习通对接字段映射.md` 做模板适配 | 取得校方模板/接口文档后再启用；出站 CSV 不含学生数据 |
| 8 · 发布 | 重建静态产物并推送 | 发布前检查清单见 `04_通用课程站点模板配置说明.md` 第九节 |
