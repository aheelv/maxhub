## 第一部分　发布版本总述

### 1.1 本版本定位与效力

本版本承接蓝图，不新增、不删减、不重排任何结构约定。其工作对象是**内容口径而非结构蓝图**：把散落在蓝图六个视图、六份说明文档、结构化真值源与构建产物中的信息项，按左、右两侧归并成一份可直接用于发布的单一版本，并对每一项内容给出发布处置与衔接标注。

本版本确认四项结果：整合后的结构、完整的内容清单、逐项衔接标注、发布就绪度判定。四者共用同一套稳定 ID、状态词表与可见性词表，不允许各栏目自行解释。

### 1.2 左、右两侧的定义与整合口径

本版本所称「左、右两侧」，指蓝图超星对接视图中并列呈现的两个信息体系；在字段映射表中，左右两侧另有字段级含义。两者统一如下：

| 侧别 | 含义 | 承载对象 | 权威定位 |
| --- | --- | --- | --- |
| 左侧 | 课程站点侧；字段映射表中为站点内部标准字段 canonical | 教材、课件、大纲、日历骨架、教案、习题、实践包、知识点、术语、案例、素材、导航与结构化数据出口 | 课程内容主数据源（Content Master） |
| 右侧 | 超星学习通／泛雅平台侧；字段映射表中为平台字段、栏目或功能对象 | 身份与选课、在线作答、成绩、签到、讨论、通知、问卷、图谱展示与掌握度计算、任务点与资料库引用 | 教学运行与学情主系统（System of Record） |

整合的三类对象：**信息项**（左右各自有哪些内容、哪些字段、哪些页面）、**层级**（各自的父子结构与对齐锚点）、**关联关系**（有向谓词、平台前置／后置／关联、外链引用）。整合的三项动作：消除重复、补齐缺失、统一表述。

贯穿全局的纪律：同一类数据只有一个权威源；左侧标准字段为唯一命名依据，适配层只做转换，平台字段不得反向污染站点模型；任何未见来源的取值一律保持空值并显式标注，不以推测补齐。

## 第四部分　衔接标注：与超星资源深度衔接的范围与要求

### 4.1 标注体系

| 方式 | 名称 | 本质 | 覆盖的信息流 | 不覆盖的信息流 |

| 方式 B | 在超星中嵌入本课程链接 | 以稳定 URL 为单位的页面级引用 | 超星课程空间引用站点公开页面与课次聚合页 | 不复制内容原件、不回写正文、不引入学生数据 |

- 单一权威源：出站课程内容以左侧为准，入站学情以右侧为准；不对同一字段双向写回。
- 只引用不复制：超星侧尽量以公开外链引用原件；确需上传副本时，副本不得回写、不得成为第二原件。
- 差异报告：超星侧的人工增补只进入差异报告，由课程组核对后再决定是否回灌左侧。
- 版本对齐：每次内容发布以版本号与内容 ID 为幂等键；课次编号、知识点编号、资源 ID 在两侧必须保持一致。

- 待核验纪律：49 个字段的平台接口列名当前全部为空；取得校方模板或授权接口文档前不得写死，功能可核验不等于列名可核验。

方式 B 的前提与限制：站点须为公开可访问的静态发布版本；课程空间 URL 仍待校方提供，当前不得写死；URL 与内容 ID 一经发布即锁定；方式 B 不产生、不传输、不展示任何学生数据；题目正文与知识点数据仍以方式 A 导入，方式 B 只做说明性与学习路径回链。

### 4.4 两种方式的组合、互斥与共同禁用项

| 情形 | 结论 |
| --- | --- |
| 仅采用方式 A | 可独立完成课程内容交换；超星侧以学生任务点与资料引用为主，无需站点外链体系 |
| 仅采用方式 B | 可完成学习路径引导；但知识点、题目与资源的结构化数据仍留在站点，超星侧不产生结构化副本 |
| 两种方式并行 | 推荐组合：方式 A 负责结构化数据，方式 B 负责学习路径入口；两者必须指向同一份原件、同一套稳定 ID 与同一版本号 |
| 互斥关系 | 方式 B 不能替代方式 A 的入站边界；方式 A 的入站数据不得因启用方式 B 而出现在公开页面或超星外链中 |
