# 可复用通用课程站点模板 · 固定结构 · 可配置项 · 套用说明

> 文档性质：信息架构交付物 ④
> 模板包位置：`course-template/`；模板自带说明：`course-template/README.md`
> 配置规范：`course-template/schema/course.config.schema.json`
> 示例与实例：`config/course.config.example.json`、`config/人工智能工具应用实践.config.json`

---

## 一、模板定位

模板交付的不是一套写死内容的网页，而是**结构 + 契约 + 工具**三件套：

| 组成 | 内容 | 是否随课程变化 |
| --- | --- | --- |
| **固定结构** | 目录约定、URL 约定、17 种内容类型、20 项公共元数据、14 种关联谓词、栏目层级、导航规则、素材 A/B/C 分级、对接协议、构建与校验管线 | ❌ 不变 |
| **按课程可配置项** | 课程标识与题目、学分学时、模块与课次、工具、导航文案与顺序、主题色、功能开关、对接开关、内容原件路径、构建输出 | ✅ 变 |
| **课程内容数据** | `data/` 下的内容实例、知识点、术语、案例、日历、教案 | ✅ 变 |

**设计目标**：另一门课只需（1）复制示例配置并改课次与文案，（2）运行脚手架，（3）按内容类型填内容，即可获得同样的信息架构、导航、站点地图、知识图谱导出与超星对接能力，无需重新设计栏目。

## 二、固定结构清单（不得逐课修改）

| 路径 | 固定内容 |
| --- | --- |
| `model/content-types.json` | 17 种内容类型、ID/URL 规则、状态词表（`published / needs-review / draft / 待补充`）、可见性词表（`public / campus / teacher / internal`）、素材分级 A/B/C |
| `model/relation-vocabulary.json` | 14 种有向关联谓词及与超星「前置/后置/关联」的对应 |
| `model/sitemap.json` | 35 个栏目节点、L0—L4 层级、URL 约定、现状迁移映射 |
| `model/chaoxing-field-mapping.json` | 8 类数据集、字段映射契约、权威源、冲突规则、职责矩阵 |
| `schema/course.config.schema.json` | 可配置项的类型、枚举、上下限与交叉约束 |
| `schema/content-instance.schema.json` | 20 项公共元数据 |
| `schema/chaoxing-mapping.schema.json` | 映射契约结构约束 |
| `tools/validate.py` | 离线校验（零第三方依赖） |
| `tools/build_indexes.py` | 生成导航、站点地图、检索索引、出站/入站 CSV |
| `tools/scaffold.py` | 从配置生成新课程包 |

**固定规则清单**：

1. 单课程为根、`course_id` 全站一致。
2. **课次为唯一组织轴**：7 类内容以 `session_no` 对齐，`aligned_with` 关联到课次。
3. 课次聚合页是教与学的统一入口，固定六大内容标签。
4. 主导航 ≤ 7 项、≤ 2 层；任何内容 3 次点击可达。
5. 面包屑固定为「课程 › 模块 › 课次 › 内容类型 › 内容实例」。
6. 三条贯通路径：按课次 / 按知识点 / 按任务，在课次聚合页汇合。
7. 素材 A/B/C 分级；A 类必带来源、抓取日期、使用场景；C 类不提供图像与结论。
8. URL 小写 ASCII 目录式；稳定 ID 与 URL 解耦。
9. 站点不承担身份、选课、作答、成绩、签到、讨论、个人通知；`site_accounts` 与 `site_gradebook` 必须为 `false`。
10. 学生数据与个人级学情只进 `_restricted/`，静态发布排除。
11. 超星接口字段名在取得校方文档前一律为 `null`。
12. 一份内容一个原件；超星侧只引用，副本不回写。

## 三、按课程可配置项全表

字段名、类型、必填与约束以 `schema/course.config.schema.json` 为准，下表为使用说明。

### 3.1 课程标识与基本参数

| 字段 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| `course_id` | string | ✓ | 稳定标识，正则 `^[A-Z0-9][A-Z0-9_-]{2,39}$`；发布后不得变更 |
| `title` | string | ✓ | 课程题目，全站主线 |
| `subtitle` | string\|null | — | 一句话定位 |
| `course_type` | enum | ✓ | 专业选修课 / 专业必修课 / 通识课 / 公共基础课 / 实训课 / 其他 |
| `school` / `department` / `major` | string\|null | — | 开课单位与适用专业 |
| `course_code` | string\|null | — | **教务编码；无来源必须为 null** |
| `credits` / `hours` | number / int | ✓(hours) | 学分、总学时 |
| `session_count` | int | ✓ | 课次数，1—64；须等于 `sessions` 长度 |
| `session_minutes` | int | ✓ | 单次课分钟数 |
| `lecture_minutes` / `practice_minutes` | int | ✓ | 二者之和须等于 `session_minutes` |
| `term` / `calendar_start` | string\|null / date\|null | — | 无校历时为 null；教学日历日期不推断 |
| `language` / `license` | string | — | 默认 `zh-CN` |

### 3.2 模块与课次（主轴数据）

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `modules[]` | array(1—12) | `{id: M{n}, no, name, session_range:[起,止], accent}`；所有区间须完整、无重叠地覆盖 `1..session_count` |
| `sessions[]` | array(1—64) | `{no, title, module_id, hours, slug?}`；`no` 连续且唯一，`module_id` 必须命中模块；标题即课次聚合页标题 |
| `tools[]` | array | `{name, role, core, url, availability}`；`availability` 取 `可用 / 待开通 / 模拟演示`，防止把未开通能力写成真实可用 |

### 3.3 导航与外观

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `navigation.primary[]` | array(3—7) | `{id, label, href, children?}`，决定主导航与二级菜单；**层级规则固定，文案与顺序可配** |
| `navigation.footer[]` | array | 页脚链接 |
| `navigation.show_breadcrumb` / `show_prev_next` | boolean | 默认 true |
| `theme.preset` | enum | `light` / `high-contrast` |
| `theme.brand` / `theme.tokens` | string / object | 主色与模块色 token；`tokens` 的键须覆盖 `modules[].accent` |

### 3.4 功能开关

| 字段 | 默认 | 约束 |
| --- | --- | --- |
| `features.textbook` | true | 是否生成教材栏目 |
| `features.lesson_plan_public` | **false** | 教案默认仅教师可见；改为 true 须先完成脱敏审查 |
| `features.knowledge_graph` | true | 决定是否生成知识点页与图谱导出 |
| `features.cases` / `glossary` / `trends` / `announcements` / `downloads` | true | 关闭则不生成相应页面与导航项，内容类型仍保留在模型中 |
| `features.site_accounts` | **false** | **必须为 false**；校验器强制 |
| `features.site_gradebook` | **false** | **必须为 false**；校验器强制 |

### 3.5 对接配置

| 字段 | 说明 |
| --- | --- |
| `integration.mode` | `complementary`（默认，与超星互补）/ `standalone`（不同步） |
| `integration.chaoxing.platform_url` | 平台入口，默认 `https://i.chaoxing.com` |
| `integration.chaoxing.course_space_url` | 本校课程空间 URL；未提供为 null |
| `integration.chaoxing.sso_enabled` | 默认 false |
| `integration.chaoxing.api_contract_status` | `已获取校方接口文档` / `待核验`；**为「待核验」时校验器禁止写死接口字段名** |
| `integration.datasets{}` | 8 个数据集的 `{enabled, direction, transport, frequency}`；键必须命中映射契约 |
| `integration.restricted_zone{}` | `path / publish_excluded / deidentify / retention_days` |

### 3.6 内容规则、原件路径与构建

| 字段 | 说明 |
| --- | --- |
| `content.evidence_levels_enabled` | 默认 `["A","B","C"]` |
| `content.require_source_for_A` | 默认 true |
| `content.default_visibility` | 按类型覆盖默认可见性，如 `lesson-plan: teacher` |
| `content.min_exercise_minutes` | 默认 60，习题时长下限 |
| `content.rubric_total` | 默认 100 |
| `sources{}` | 教材、课件、PPTX、习题、下载、术语、案例、截图的原件路径；构建器只读不复制 |
| `build{}` | `out_dir / base_url / static / generate[]` |
| `extensions{}` | 自由扩展键，**不得覆盖上述任何保留键** |

## 五、套用到另一门课程的完整流程

```bash
# ① 复制示例配置并编辑（改 course_id / title / modules / sessions / navigation / integration）
cp course-template/config/course.config.example.json /tmp/my-course.json

# ② 生成新课程包（固定结构原样复制，数据骨架按配置生成）
python course-template/tools/scaffold.py --config /tmp/my-course.json --out /path/to/my-course-site

# ③ 进入新课程包，按 model/content-types.json 逐类补齐内容
#    data/content-manifest.json  内容实例
#    data/graph.json             关联边
#    data/knowledge-points.json  知识点
#    data/calendar.json          教学日历（日期保持 null 直到取得校历）

# ④ 校验（零错误才算完成）
cd /path/to/my-course-site && python tools/validate.py

# ⑤ 生成导航、站点地图、检索索引与超星交换文件
python tools/build_indexes.py
```

**人工步骤清单**（模板无法代劳）：

1. 核对课程编码、学期、校历起始日、超星课程空间 URL；无来源保持 null 并在 `extensions.notes` 说明。
2. 按 `model/sitemap.json` 建立页面目录；固定结构不要改。
3. 逐类填充教材、课件、教案、日历、习题、实践包、知识点、案例、术语、素材。
4. 每个 A 类素材填写 `source`、`source_url`、`captured_at` 与使用场景；B 类标注虚构；C 类标注待补充。
5. 教师核定知识点认知维度、教学目标与语义前置/后置关系后才可发布图谱。
6. 导入超星前按映射契约核对本校模板列名与接口文档。

**实测记录**：用示例配置生成的新课程包含 2 模块 / 8 课次 / 11 个初始内容实体 / 10 条关联边，`validate.py` 158 次断言零错误，`build_indexes.py` 生成 73 条 URL、5 份出站 CSV、2 份入站模板，端到端通过。

## 六、校验规则与常见错误

`tools/validate.py` 为**零第三方依赖**的离线校验器（内置 JSON Schema 子集解释器），检查范围：

| 类别 | 检查项 |
| --- | --- |
| 配置结构 | 必填字段、类型、枚举、正则、长度、上下限、未声明字段 |
| 主轴一致性 | `sessions` 长度 = `session_count`；编号连续唯一；模块引用有效；模块区间完整覆盖；讲授+实践 = 单次课时长 |
| 去重复约束 | `site_accounts` / `site_gradebook` 必须为 false；主导航 ≤ 7 项 |
| 对接契约 | 数据集键合法；核验状态已标注；未取得接口文档时 `chaoxing_api_field` 必须为 null；高重复风险能力的站点职责已收敛 |
| 内容实例 | 类型合法、ID 唯一、状态/可见性/证据等级词表、A 类来源与抓取日期、文件真实存在、知识点引用有效 |
| 关联图 | 谓词合法、边端点存在、重复边告警 |

| 常见错误 | 原因 | 修正 |
| --- | --- | --- |
| `sessions 数量 ≠ session_count` | 增删课次只改了一处 | 同步修改 `session_count` 与 `sessions[]` |
| `模块区间未完整覆盖` | 模块 `session_range` 有缺口或重叠 | 调整区间，校验器会列出缺失课次 |
| `讲授 + 实践 ≠ 单次课分钟` | 三项参数不自洽 | 按课程实际学时修正 |
| `A 类素材缺 source / captured_at` | 引用了外部截图但未记录来源 | 补齐来源 URL 与抓取日期，或降级为 C 类「待补充」 |
| `引用的文件不存在` | 内容实例 `files[].path` 写错 | 路径相对项目根；由 `build_template_data.py` 自动生成可避免 |
| `chaoxing_api_field 不应写死` | 未取得接口文档却填了猜测字段名 | 置 null；取得文档后再把 `api_contract_status` 改为「已获取校方接口文档」 |
| `未定义谓词` | `graph.json` 用了词表外的关系 | 使用 `model/relation-vocabulary.json` 中的 14 种谓词 |

## 七、构建产物说明

`tools/build_indexes.py` 从配置 + 站点地图 + 内容清单生成 `dist/`：

| 产物 | 用途 |
| --- | --- |
| `nav.json` | 全站导航（含 16 课次子项与课次六大标签定义） |
| `sitemap.json` / `sitemap.xml` | 具体 URL 清单（本课程 215 条） |
| `search-index.json` | 公开可检索条目（本课程 355 条；排除 `待补充` 与非公开内容） |
| `content/graph.json`、`content/content-manifest.json` | 站内渲染与超星适配层消费的数据出口 |
| `export/*.csv` | 出站 5 份：知识图谱、课程结构、题库、资源清单、教学日历 |
| `import/*.template.csv` | 入站 2 份：学情、学生名单（**仅表头，无数据**） |
| `README.txt` | 构建摘要 |

`dist/` 是可随时重建的生成物，不手工编辑。出站 CSV 采用 UTF-8 BOM，每份附 `.readme.txt` 说明列名适配与隐私约束。

## 八、扩展与版本管理

- **新增内容类型**：需同时修改 `model/content-types.json`、`schema/content-instance.schema.json`、`tools/validate.py` 的类型检查，并在 `model/CHANGELOG.md` 记录；不允许只加页面不改模型。
- **新增关联谓词**：需修改 `model/relation-vocabulary.json`，并说明与超星关系的映射（或明确标注"仅站内导航，不导出"）。
- **新增数据集**：需修改 `model/chaoxing-field-mapping.json` 与 `config.integration.datasets`，每个字段必须标注核验状态。
- **课程版本**：按学期新建课程包（与 GitHub 同类模板的"按学期新建仓库"实践一致）；`course_id` 保持稳定，开课轮次写入 `term` 与 `extensions`。
- **固定结构升级**：以模板包版本号统一管理，新课程包通过 `scaffold.py` 复制获得；旧包不自动升级，避免破坏已发布内容。

## 十、与当前现网站点的关系

本模板包是**独立于 `site/` 的架构层交付**：`site/` 下 15 个 HTML、16 个 deck JS、后端与数据库均未改动，已发布的 GitHub Pages 站点保持原状。落地时按 `01_站点地图.md` 第七节的 8 个阶段逐步迁移；`course-template/dist/` 的导航、站点地图与检索索引可直接作为新页面的数据入口，`export/*.csv` 可直接作为超星导入的输入。
