# 校园咖啡角 · 3 月经营笔记（课堂虚构材料）

> 说明：本材料为店长口述整理，含重复段落、两处前后不一致的营收数字与一段无关的值班表。使用前不得自行「修正」任何数字。

## 一、本月总体情况

3 月开学后客流回升，工作日早上 7:40—8:20 是最忙的时段，经常排到门口。店长口头说，3 月营收是 ¥48,600，比 2 月好了不少。本月上新了燕麦拿铁和柠檬冷萃两款，燕麦拿铁卖得比预期好。周末客流反而平稳，主要是自习的同学坐得久、翻台低。

**重复段落（与上段内容相同，供清洗练习）**：3 月开学后客流回升，工作日早上 7:40—8:20 最忙，经常排到门口。本月上新燕麦拿铁与柠檬冷萃，燕麦拿铁卖得比预期好。周末客流平稳，自习同学坐得久、翻台低。

## 二、成本与出杯

原料成本本月约 ¥19,440，其中豆子与牛奶占大头；一次性杯盖与吸管约 ¥2,430；水电与设备维护约 ¥1,800；兼职排班人工约 ¥9,720。以上四项合计约 ¥33,390。出杯量按收银系统记录约 4,050 杯，客单价按店长口径约 ¥12/杯。

**注意**：财务在另一页手写补充中写「3 月营收 ¥51,200」。两处数字不一致，原因未查明，请勿自行取平均、勿任选其一、勿推算「真实值」。

## 三、顾客反馈

留言本上出现较多的三条：一是早高峰等太久；二是希望增加无糖选项；三是希望支持提前下单到店自取。有同学提到柠檬冷萃偏酸，也有同学说很喜欢，评价不一致。店长认为可以先试一周提前下单，但没定具体做法。
