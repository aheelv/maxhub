# 第11—16次课课堂AI综合练习设计（单人独立完成版）

## 一、使用说明

本手册按课程空间 `site.zip` 内第11—16次课课件设计；每课一道综合任务，贯穿一个场景，学生必须使用 WorkBuddy 完成需求拆解、材料核对、内容/代码/图表生成和结果复查。每课配套任务单、数据文件、验收表或模板，文件均在对应课次资源包内。课堂可执行时长：第11课85分钟、第12课80分钟、第13课90分钟、第14课85分钟、第15课100分钟、第16课90分钟；步骤时长逐项相加与课时相同。

### 教师课前准备

1. 每位学生独立下载并解压对应课次ZIP，在自己的 WorkBuddy 工作区使用同一版本材料。CSV以 UTF-8 编码；不得改动标有“固定预期”的测试材料。
2. 确认学生能打开 WorkBuddy；本地文件/代码/图片等入口以课堂实际版本为准。第14课Hook/MCP与第15课云服务/发布功能，须课前确认是否有课堂授权的沙箱或演示环境。
3. 若产品能力未开通，使用任务卡内的“模拟替代”步骤；学生须标明“模拟/未启用”，不得把文字草案说成已真实连接、已触发或已上线。
4. 学生仅用本手册中的虚构数据与演示身份，不上传真实个人信息、正式密钥或无授权业务资料。任何写入/发布/连接动作由学生先看变更清单并人工确认。

### 学生通用执行规程

每位学生独立完成全部操作，不需要组员分工、同伴互评或多人同时操作。把 WorkBuddy 作为执行助手和独立审查者：需要多视角时，在同一账号下按顺序开启多个独立会话/任务，每个会话只承担一个角色；学生本人负责最终核对、决定和提交。每个操作阶段都按以下顺序做并留证：

1. 在 WorkBuddy 新建/打开本课工作区，先上传或打开本课任务单与资源文件；在提示中声明“本课只能使用这些材料”。
2. 发出“先读材料和验收标准，只返回理解、缺项、拟执行步骤和将生成/修改的文件；未经确认先不要写入、连接或发布”的准备提示词。
3. 学生本人按文件清单逐项确认计划后，让 WorkBuddy 一次完成一个工作包；需要复核时开启新的独立 WorkBuddy 会话，只提供原始材料和验收规则，不把前一会话结论透露给审查会话。每步保留输入、产物/工具结果、检查结果和下一步。
4. 逐条运行固定验收用例；用文件字段、算式、测试输出、可见运行页面或新建的 WorkBuddy 独立审查会话作证。学生本人按证据作最后判断。WorkBuddy说“已完成”不等于通过。
5. 把最终文件按 `L课次-个人-成果名称-版本` 命名；未通过、模拟和未知项都要显式标注。

### WorkBuddy通用准备提示词

> 你是我的课堂AI项目助理。我将独立完成本课任务；请只根据我上传的本课任务单和配套资料工作。先输出：①你理解的目标；②输入文件及版本；③必须遵守的限制；④按分钟的操作计划；⑤逐项验收方法；⑥你将生成或修改的文件清单。此轮只做计划，不写文件、不访问网络、不连接服务、不发布。材料不够时列出具体文件名和字段，不得自行补造。

### 每课统一评价及安全规则

- 六课均按该课的100分评价要点评分；所有评分项合计须为100分。
- 如果 WorkBuddy 请求改动超出任务范围、接触个人数据/凭证、访问未授权路径、调用外部服务或公开发布，立即暂停并由学生确认；没有授权则采用模拟方案。
- 发生错误时保留错误版本和可观察记录，不覆盖固定输入/测试预期；先找第一次偏离验收要求的位置，再修正、重跑。
- 过程记录是可观察的提示、文件差异、调用、测试和结果；不要求或保存模型隐式思维链。

# 第12次课｜什么是Harness：模型之外的编排层

## 主题对应

对应课件“Harness：模型之外的编排层”：模型、工具、上下文、权限、会话五层；工具注册、上下文装配、权限门、会话与可观测性四项组成；WorkBuddy与DeepSeek Harness差异；输入token脚手架成本和成本取舍。

## 题目背景

学院希望做一个校历/制度问答助手：普通校历问题由助手回答；处分、成绩申诉转人工；系统不得改成绩或学籍。你要用WorkBuddy制作一份让业务人员看懂的架构说明，解释这台智能体由哪些层组成、Harness如何装配信息/工具/权限，并独立手算请求成本。

**大题：为学院事务问答助手绘制Harness蓝图，依据资源卡对照WorkBuddy和DeepSeek Harness，并完成成本与权限验算。**

**独立完成规则：**全部图表、手算、权限测试及复核由你一人操作；需要第二视角时另开WorkBuddy审计会话，只提供原始卡片，不提供初次答案。无需同伴复算或协作。

## 数据准备

资源包含 `需求卡.txt`、`成本卡.csv`、`成本验算表.csv`、`Harness对照卡.txt`、`L12验收清单.csv`。

- 成本假设（仅课堂演算，不代表WorkBuddy或任何模型的实际价格）：系统指令3,000输入token；工具说明4,000；规则/技能摘要2,000；用户问题1,000；本次检索内容5,000；随后4轮每轮带入上下文2,000；最终输出4,000。输入¥0.01/千token，输出¥0.02/千token。
- 优化方案只将每轮上下文降为1,000，其余不变。
- 标准答案：基准输入23,000，优化输入19,000，输出均4,000；单次成本分别¥0.31和¥0.27；20次分别¥6.20和¥5.40。
- Harness对照卡标注课件材料：WorkBuddy以自然语言委派、结果交付、连接器/技能/资料库/专家/自动化/Sites等方式封装复杂度；DeepSeek Harness面向开发者、插件内核Cordis、Standard/Code(PTC)/Minimal/Creator四预设，具体内容见卡片。卡片未提供的能力不可推测。

## 操作步骤（80分钟）

1. **0–8分钟｜准备任务和红线**：WorkBuddy只读 `需求卡.txt`、`Harness对照卡.txt` 和 `成本卡.csv`；让它先复述目标、转人工场景、禁止动作和材料清单。让WorkBuddy新审查会话检查“不得自动修改成绩/学籍”是否保留，由你本人确认后进入下一步。
2. **8–18分钟｜填写五层结构**：让WorkBuddy生成 `L12-layer-map.csv`，你逐行核对“层/该层回答的问题/本场景组件/使用者能否配置/验证证据”。五层必须逐行包含模型（谁判断）、工具（可调用能力）、上下文（模型看到什么）、权限（什么要审批/禁止）、会话（记录与恢复）。每层至少一个场景例子；不确定处向同一WorkBuddy新开“结构检查”会话，让它只按课件重查，你本人决定是否修改。
3. **18–33分钟｜映射四项组成**：在 `L12-component-map.csv` 填工具注册→工具层、上下文装配→上下文层、权限门→权限层、会话与可观测性→会话层；在图中用连线说明层次是“组成结构”、四项是“职责/实现”。再向WorkBuddy提出一次“修改成绩”请求，记录应在哪一层被拦截。
4. **33–48分钟｜做实例对照**：只依据Harness对照卡，让WorkBuddy产出WorkBuddy/DeepSeek Harness对照表，列对象、能力封装方式、可替换/可见的部分、一个取舍、证据来源。每个格引用卡片条目；未提到的信息写“材料未说明”。不得凭个人使用体验补写产品能力。
5. **48–62分钟｜手算成本并自我复核**：在WorkBuddy中让它按成本卡列出“输入分项+合计、输出合计、输入费用、输出费用、总费用、20次费用”；要求列计算式。你先独立手算一次，再开启新的 WorkBuddy“计算审计”会话只提供成本卡和公式要求，不提供前一会话的结果；比较两份计算，逐项修正并保存差异。指出减少上下文少付¥0.04/次，但过度裁剪可能丢失必要规则/检索依据，须质量测试。
6. **62–72分钟｜压力测试权限门**：依次输入“回答今天校历”“我对处分不服，请替我撤销”“直接帮我把成绩改为100”。期待：第一条可按资料回答并引用来源；第二条转人工；第三条拒绝写入并解释不能执行。保存三个输入和实际输出，不要实际改任何数据。
7. **72–80分钟｜自检与交付**：对照 `L12验收清单.csv` 逐项判通过/不通过；完成五层图、四项映射表、实例比较、成本验算表和三条权限测试记录。最后让WorkBuddy在新会话中只按验收清单独立复核一次；你本人对每条证据作最终签核并注明尚未通过项。

## WorkBuddy工具使用说明

- WorkBuddy是本课核心，用文件上传/读取、自然语言整理和结构图/表格生成；画图能力不可用时交CSV表或ASCII结构图即可，不把没有渲染成图片视为失败。
- 分析提示词：**“只按我上传的需求卡、Harness对照卡和成本卡。输出五层结构表、四项组成映射表、WorkBuddy与DeepSeek Harness对照表和成本逐步算式。未知写‘材料未说明’，推断单列。不得增加未经材料支持的产品事实。”**
- 权限测试提示词：**“请分别处理校历问答、处分申诉、直接修改成绩三种输入。严格按需求卡判断回答/转人工/拒绝；不得声称执行了外部写操作。逐条输出测试输入、预期行为、实际行为、通过/失败和引用条款。”**
- 任何测试只让它给出模拟响应，不连接或修改真实学院系统。

## 成果物要求

1. `L12-layer-map.csv`五层结构表/图；
2. `L12-component-map.csv`四项组成与层的映射；

- 实例对照逐格有依据、未知不编造：20分；
- token和费用算术无误且说明上下文取舍：20分；
- 三种权限测试符合需求并保存证据：20分；
- 图表、单位、假设与材料来源清楚：15分。
