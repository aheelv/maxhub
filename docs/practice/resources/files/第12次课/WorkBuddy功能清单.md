# 第 12 次课｜WorkBuddy 功能覆盖清单

> Harness结构与成本 · 80 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 用量与开销观察 | 让 AI 先报将加载哪些工具与规则，再执行 | 开销说明与用量记录 | ☐ |
| 预设 / 运行时对照 | 对比两种预设的步骤、用量与结果 | 对照记录表 | ☐ |
| 表格计算 | 按成本卡逐项验算固定开销占比 | 成本验算表.csv | ☐ |
| 多会话独立核对 | 新会话独立复核组成映射与权限测试 | 两个会话提示词对比 | ☐ |
| 配置说明文档 | 写一页可复现的配置说明 | 配置说明 md | ☐ |
| 资料库归档 | 把映射表、验算表与说明归档 | 工作区文件清单 | ☐ |

共 **6 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
