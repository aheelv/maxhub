# 第11—16次课课堂AI综合练习设计（单人独立完成版）

## 一、使用说明

本手册按课程空间 `site.zip` 内第11—16次课课件设计；每课一道综合任务，贯穿一个场景，学生必须使用 WorkBuddy 完成需求拆解、材料核对、内容/代码/图表生成和结果复查。每课配套任务单、数据文件、验收表或模板，文件均在对应课次资源包内。课堂可执行时长：第11课85分钟、第12课80分钟、第13课90分钟、第14课85分钟、第15课100分钟、第16课90分钟；步骤时长逐项相加与课时相同。

### 教师课前准备

1. 每位学生独立下载并解压对应课次ZIP，在自己的 WorkBuddy 工作区使用同一版本材料。CSV以 UTF-8 编码；不得改动标有“固定预期”的测试材料。
2. 确认学生能打开 WorkBuddy；本地文件/代码/图片等入口以课堂实际版本为准。第14课Hook/MCP与第15课云服务/发布功能，须课前确认是否有课堂授权的沙箱或演示环境。
3. 若产品能力未开通，使用任务卡内的“模拟替代”步骤；学生须标明“模拟/未启用”，不得把文字草案说成已真实连接、已触发或已上线。
4. 学生仅用本手册中的虚构数据与演示身份，不上传真实个人信息、正式密钥或无授权业务资料。任何写入/发布/连接动作由学生先看变更清单并人工确认。

### 学生通用执行规程

每位学生独立完成全部操作，不需要组员分工、同伴互评或多人同时操作。把 WorkBuddy 作为执行助手和独立审查者：需要多视角时，在同一账号下按顺序开启多个独立会话/任务，每个会话只承担一个角色；学生本人负责最终核对、决定和提交。每个操作阶段都按以下顺序做并留证：

1. 在 WorkBuddy 新建/打开本课工作区，先上传或打开本课任务单与资源文件；在提示中声明“本课只能使用这些材料”。
2. 发出“先读材料和验收标准，只返回理解、缺项、拟执行步骤和将生成/修改的文件；未经确认先不要写入、连接或发布”的准备提示词。
3. 学生本人按文件清单逐项确认计划后，让 WorkBuddy 一次完成一个工作包；需要复核时开启新的独立 WorkBuddy 会话，只提供原始材料和验收规则，不把前一会话结论透露给审查会话。每步保留输入、产物/工具结果、检查结果和下一步。
4. 逐条运行固定验收用例；用文件字段、算式、测试输出、可见运行页面或新建的 WorkBuddy 独立审查会话作证。学生本人按证据作最后判断。WorkBuddy说“已完成”不等于通过。
5. 把最终文件按 `L课次-个人-成果名称-版本` 命名；未通过、模拟和未知项都要显式标注。

### WorkBuddy通用准备提示词

> 你是我的课堂AI项目助理。我将独立完成本课任务；请只根据我上传的本课任务单和配套资料工作。先输出：①你理解的目标；②输入文件及版本；③必须遵守的限制；④按分钟的操作计划；⑤逐项验收方法；⑥你将生成或修改的文件清单。此轮只做计划，不写文件、不访问网络、不连接服务、不发布。材料不够时列出具体文件名和字段，不得自行补造。

### 每课统一评价及安全规则

- 六课均按该课的100分评价要点评分；所有评分项合计须为100分。
- 如果 WorkBuddy 请求改动超出任务范围、接触个人数据/凭证、访问未授权路径、调用外部服务或公开发布，立即暂停并由学生确认；没有授权则采用模拟方案。
- 发生错误时保留错误版本和可观察记录，不覆盖固定输入/测试预期；先找第一次偏离验收要求的位置，再修正、重跑。
- 过程记录是可观察的提示、文件差异、调用、测试和结果；不要求或保存模型隐式思维链。

# 第16次课｜综合项目答辩与技术前沿展望

## 主题对应

对应课件“综合项目答辩与技术前沿展望”：项目答辩五项标准（选题价值、技术实现、数据与证据、表达、可复现性）；5分钟讲述、评委打分与质询；AI Index 2026数据的来源/统计对象/限定语；AI治理、责任使用、能力建设和三个月行动清单。

## 题目背景

你将独立完成一场模拟答辩，项目使用个人在第15课完成的活动报名页，或资源包中的统一演示项目。WorkBuddy将扮演模拟评委，按“用户问题—现场运行—数据证据—复现办法”提出质询。引用数据不是装饰，必须给出来源、年份、统计对象、分母/口径和不能推出的结论；全程不需要真人评委或其他学生。

**大题：用 WorkBuddy 完成5分钟项目答辩材料，现场演示并回应两轮固定质询，提交证据卡、评分修订和个人三个月行动计划。**

**独立完成规则：**全部准备、演示、答问与反思由你一人完成。质询者由WorkBuddy独立新会话模拟；先自评，再让盲审会话按同一量表评分。没有真人评委、听众或同伴互评要求。

## 数据准备

资源包含 `L16-evidence-cards.csv`、`L16-scoring-rubric.csv`、`5min-outline.txt`、`repro-checklist.txt`、项目演示证据登记表。

课件证据卡预填公开来源标签，学生需用课件原页核对并补适用范围/限制：

- 斯坦福HAI《2026 AI Index Report》（2026-04-13）：组织AI采用率2025年88%、2024年78%；生成式AI三年内全球使用率53%。不能由采用率推出ROI或每个组织都用得有效。
- 同报告：记录的AI事件2024年233起、2025年362起；透明度指数平均分58降到40。不得据此断言所有产品都不透明或全部事件由同一原因造成。
- MIT NANDA《The GenAI Divide: State of AI in Business 2025》：约95%的企业GenAI试点未产生可衡量财务回报；报告另指出自建工具是失败的重要预测因素。样本分母如课件未提供，卡片必须写“课件未提供，不推算”。
- McKinsey《The State of AI》（2025）：88%组织至少在一个职能使用AI；约6%为AI对EBIT影响超过5%的高绩效者。两个百分比指标定义和统计对象不同，不能当成同一分母上的互补比例。
- METR（2025）公开研究：对象为资深开源开发者，在其熟悉代码库的任务中，使用AI完成任务速度反而慢19%。不得推广成“AI让所有开发者所有任务变慢”。
- 其他课件证据如SWE-bench、2.7%差距、治理日期等，仅在资源卡列出原始口径时使用；未在卡片中提供的对象/分母不得猜。

你从卡中独立选至少3条，在“引用表”填数字、原始来源、年份、对象、统计口径/分母（未给则明示）、限制、不可推出结论及课件页/卡片行。课件材料和项目实测数据分开标注；WorkBuddy只检查遗漏项，你本人确认原始依据。

## 操作步骤（90分钟）

1. **0–10分钟｜建项目证据包**：用WorkBuddy读项目README、运行说明和测试记录；生成 `L16-claim-register.csv`，将句子分“已有文件/运行证据支持、待验证、目前不成立”。记录项目版本和本地/线上状态。
2. **10–22分钟｜按固定页序写5页答辩稿**：①用户与痛点；②最小技术方案；③现场演示步骤；④一个项目实测证据+至少3条课件前沿证据；⑤限制、风险和下一步。每页只有一个中心结论，每个数字直接附来源脚注，不用“网上有研究说”。
3. **22–42分钟｜核查数据和推理**：WorkBuddy按证据卡逐项查来源/年份/对象/口径/限定语，缺项标“需回查”。再新开一条独立 WorkBuddy“事实审查”会话，只提供证据卡和课件定位，不提供第一会话的解释，要求它找出不一致处。你本人比较两份输出并写出：MIT约95%与McKinsey约6%不是同一指标，不能相减或互相否定；METR是特定人群/熟悉代码库/特定任务实验，不等同所有开发工作。错误或无来源数字删除或改成“待核实”。
4. **42–62分钟｜5分钟现场演示排练**：计时结构固定：0:00–0:30用户/痛点/当前能力；0:30–3:00真实运行主流程；3:00–4:00展示项目测试结果和至少一条带来源的行业数据；4:00–5:00说局限、风险和下一步。不得用预录成功视频代替现场运行；断网时使用本地版本并如实说明。
5. **62–74分钟｜WorkBuddy模拟两轮质询**：在WorkBuddy新建“独立评委”会话，提供五页大纲和证据卡但不提供你的预先答案。让它只问两题：①“这个数字来源、年份、分母和适用范围是什么？”②“换到干净设备如何复现？”你本人逐题口头计时回答，并把答案指向 `L16-evidence-cards.csv` 行或具体文件/命令；WorkBuddy审查会话再按量表核对，答不上就登记缺口，不现场编造。该评委为AI模拟，不称真人评审。
6. **74–84分钟｜独立评分并定向修订**：你先按选题价值20、技术实现25、数据与证据25、表达15、可复现性15自行打分，合计100；再让WorkBuddy开启新的“盲审评委”会话，只看你的答辩稿与rubric，不看自评分，独立给分并指出证据缺口。对照两份分数，选最低两项，各写“原证据—修改动作—修改后证据”。三个月计划作为个人结项必交，不重复计入项目答辩分。
7. **84–90分钟｜个人三个月计划**：填写每月一个明确目标、完成日期、可观察成果、自查方法/复盘日期和AI使用边界；例如“11月底提交一次可复现测试报告”，不写“提升AI能力”。

## WorkBuddy工具使用说明

- 用WorkBuddy读取项目证据和课堂证据卡，先输出事实登记表/5页大纲，不让它搜索后补“看似可信”的来源。
- 大纲提示词：**“只根据我提供的项目说明、测试记录和L16-evidence-cards.csv。生成五页答辩大纲；所有行业数字需带卡片编号、来源、年份、对象、口径与限定语。卡片没有分母则写‘课件未提供’，不能推算。把项目实测与外部统计分栏；不得增加外部数字或虚构链接。”**
- AI模拟评委提示词：**“你是本次个人答辩的模拟评委，不需要真人同场。按选题价值20、技术实现25、数据与证据25、表达15、可复现性15独立评分，总分100。每项写证据位置、缺口和修订动作；重点检查统计口径、相关/因果、现场运行与预录视频差异。不要因为我是单人完成而降低项目目标或难度。”**
- 允许用WorkBuddy演示文稿生成能力产出5页PPT；生成后需逐页对照证据卡。无PPT能力时交相同页序的讲稿，不将格式降级误当内容缺失。

## 成果物要求

1. 5页答辩PPT或按固定页序的5页讲稿；
2. 5分钟计时稿和现场演示清单；
3. 至少3条经核验的AI Index证据卡及项目证据登记表；
4. 五项个人自评分表、WorkBuddy模拟评委评分、两轮答辩回答记录、最低两项的修订前后证据；
5. 个人三个月计划和复现检查清单。

## 评价要点（100分）

- 项目选题价值/目标用户具体：20分；
- 技术实现真实、演示与测试对应：25分；
- 数据与证据来源、年份、口径、限定语准确：25分；
- 5分钟表达结构和答问：15分；
- 他人复现所需版本、依赖、运行步骤完整：15分。
