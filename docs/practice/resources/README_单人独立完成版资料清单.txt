第11—16次课课堂AI综合练习（单人独立完成版）

## 适用方式
所有活动由一名学生单独完成，不需要组员分工、同伴互评、第二名账号操作者或真人评委。WorkBuddy用于分析、生成和审查；需要多视角时，由同一学生按顺序开启不同独立会话模拟角色。学生本人负责最终判断、测试、签核和提交。

## 建议入口
1. `第11-16次课课堂AI综合练习设计_单人独立完成版.docx`：六课完整手册。
2. `第11-16次课课堂AI综合练习设计_单人独立完成版.md`：可检索、复制的源稿。
3. `资源包_第N次课_*.zip`：按课次打包的完整任务单、数据、模板、验收表和教师核验卡。
4. `files/第N次课/`：逐份下载文件；与对应课次ZIP内容一致。
5. `第11-16次课课堂练习资源全包_单人独立版.zip`：完整手册与六课资源包合集。

每课任务单都包含主题对应、题目背景、数据准备、分钟级独立步骤、WorkBuddy提示词/操作方法、成果物和100分评价标准。时长：第11课85分钟、第12课80分钟、第13课90分钟、第14课85分钟、第15课100分钟、第16课90分钟。多智能体拓扑、子代理、辩论/投票、独立审查和答辩质询等多角色环节均由单人通过WorkBuddy多个隔离会话模拟，结论由学生本人核验。

## 安全与环境说明
所有数据、活动和身份均为虚构。云服务、Hook、子代理、Creator、MCP和发布功能按课堂授权及当前版本支持情况使用；无法真实启用时按任务单模拟并明确标注，不得把模拟说成真实运行。MCP说明卡不是可直接启用的服务配置。SQL文件仅为字段示意，须先核对实际课堂云服务。教师核验卡含参考结果，建议教师在学生提交后再发放。
