模块详解

每个模块都给出「核心概念 — 关键工具 — 能达到的能力」。

MODULE 01 · 6 课时

AI 基础与背景

为后续一切工具实践建立认知地基，讲清 AI 的来龙去脉与能力边界。

人工智能发展史机器学习 / 深度学习 Transformer大语言模型 生成式 AI多模态提示工程

能力产出：能准确解释大模型能做什么、不能做什么；能写出结构化、可复用的高质量提示。

MODULE 02 · 8 课时

AI 办公与数据分析

把 AI 变成日常生产力，覆盖文档、演示、表格与分析全链路。

AI 写作AI 生成 PPT 会议纪要智能表格 公式与清洗自然语言分析BI × AI

能力产出：能用一份原始数据独立完成从清洗、分析到「一页管理简报」的全过程。

MODULE 03 · 8 课时

智能体（Agent）技术

从会生成到会行动：理解并搭建可用的智能体系统。

Agent 循环ReAct Function CallingMCP / A2A RAG 知识库工作流编排 多智能体AgentOps

能力产出：能基于低代码平台搭建一个带知识库与工具的、可分享的智能体。

MODULE 04 · 8 课时 · 重点模块

Harness 与 AI 集成开发环境

本课程的核心增量：理解编排层机制，并用 AI IDE 把想法变成应用。

Harness 六要素上下文工程 工具执行与沙箱循环 / 重试 规则文件Hook 子代理权限模型MCP 接入

能力产出：能用自然语言驱动 AI IDE 独立完成一个小型应用 / 数据工具的构建与发布。

MODULE 05 · 2 课时

综合实践与前沿

汇聚本学期成果并展望前沿：项目答辩 + 治理伦理 + 前沿展望。

项目答辩AI 伦理 数据合规技术前沿

能力产出：完成一个可演示、可交付的综合作品，并形成个人 AI 应用方法论。
