# 第 10 次课｜WorkBuddy 功能覆盖清单

> 低代码问答智能体实战 · 90 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 文件读取与脱敏扫描 | 逐处定位 9 处敏感占位并另存 | L10-脱敏记录.csv + 脱敏后语料 | ☐ |
| 资料库 / 本地文件问答 | 按条款分块、统一命名并设边界 | 语料文件清单与边界规则 | ☐ |
| 多会话隔离 | 搭建 / 测试 / 审校三会话分离 | 三轮提示词与原始回答 | ☐ |
| 结构化测试与验收表 | 20 题三类统计 + 11 项逐项判定 | 测试报告 + L10-发布验收.csv | ☐ |
| 发布 / 页面草案（或模拟） | 按变更清单确认后发布，或产出标注清楚的草案 | 链接截图或草案文件 | ☐ |
| 版本与归档 | 故障注入—回滚—前后证据 | L10-巡检回滚.txt 填写稿 | ☐ |

共 **6 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
