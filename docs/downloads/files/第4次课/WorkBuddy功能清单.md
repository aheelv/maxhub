# 第 4 次课｜WorkBuddy 功能覆盖清单

> 文档演示与知识归档 · 80 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 文档生成与导出（docx） | 按四件事生成 1,500 字简报并导出 | docx 文件与数字清单 | ☐ |
| 演示生成与导出（pptx） | 8 页叙事线，每页一句判断 | pptx 与 L4-八页结构表.csv | ☐ |
| 长文读取与信息抽取 | 定位重复、矛盾、无关段落 | 体检输出 + 你的原文标注 | ☐ |
| 资料库归档与模板复用 | 按规则归档并保存可复用模板 | 归档清单截图 | ☐ |
| 多会话独立检查 | 新会话按验收表查命名与缺件 | 审校提示与归档清单 | ☐ |

共 **5 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。
