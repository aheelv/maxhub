# 第 8 次课｜跑通一次端到端智能体，并拆开它的执行轨迹

> **课堂 AI 综合练习 · 单人独立完成 · 80 分钟** ｜ 模块三 · 智能体与编排
> 以 **WorkBuddy** 为主要完成工具；涉及代码、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照，但**不得把对照写成必需条件**。

## 一、任务说明

### 主题对应

对应课件《从工具到智能体：Agent 原理与 MCP 协议》：从「你问它答」到「自己规划并执行」的循环（感知—规划—调用工具—观察—迭代）、五阶段轨迹拆解、连接器的授权边界（只读 / 写入 / 发布）、以及「纯对话 vs 带工具」对比实验。

### 题目背景（背景资料）

校园「社团物资借用」要把 3 月的借用记录整理成月度小结，材料散落在多个文件里。上一届同学用纯对话工具问了三次，每次都得到一段「看起来很像」但没有真实读文件的文字；也有同学把整个目录的写权限一次性开给智能体，结果它顺手改了原始记录。你这轮要独立用 WorkBuddy 做一次受控实验：同一任务分别用「纯对话」和「带文件读取工具的智能体」跑一遍，把带工具那次的执行轨迹拆成五个阶段，定位轨迹里一次越界写入尝试，并画出一张最小权限矩阵。

### 本课大题

**由你一人用 WorkBuddy 完成《智能体端到端实验报告》：一次真实端到端任务、五阶段轨迹拆解、纯对话 vs 带工具对比表、一张连接器权限矩阵与越界处置记录。**

### 独立完成规则

全程单人完成。连接器授权必须先写「只读」再执行；任何写入、联网、发布请求都要由你本人逐次确认。若课堂环境未开通连接器，使用 agent_trace.csv 的模拟轨迹完成拆解，并全程标注「模拟轨迹 / 未真实连接」，不得写成已接入。

## 二、所需素材

本包内全部文件均为课堂虚构材料，解压后一次性上传到 WorkBuddy 本课工作区：

| 文件 | 用途说明 |
| --- | --- |
| `borrow_records_march.csv` | 3 月借用明细：物资、社团、借出/归还日期、状态 |
| `materials_catalog.csv` | 物资目录与单价（虚构，课堂模拟） |
| `task_brief.txt` | 端到端任务需求：交付物、范围、口径、边界 |
| `agent_trace.csv` | 10 步模拟执行轨迹，含 1 次越界写入尝试，供拆解与排障 |
| `L8-五阶段拆解表.csv` | 模板：阶段 / 对应步号 / 输入 / 工具动作 / 观察结果 / 是否合规 |
| `L8-权限矩阵.csv` | 模板：能力 / 纯对话 / 只读连接 / 写入 / 发布 / 本课是否授权 |
| `L8-对比实验表.csv` | 纯对话 vs 带工具：产物可核验性、数字来源、耗时、越界风险 |
| `L8-验收表.csv` | 10 项验收项与通过标准 |

另附 `教师核验卡.txt`（**建议完成后再看**）与 `使用说明.md`（16 课通用规程）。

### 固定核验结果（自检用）

1. agent_trace.csv 共 10 步，含 1 次越界写入尝试（第 07 步：试图覆盖 borrow_records_march.csv），应被拒绝并记录。
2. 五阶段为：感知与读材料 → 规划 → 调用工具 → 观察与校验 → 交付与迭代；轨迹中第 01—02 / 03 / 04—06 / 07—08 / 09—10 步分别对应。
3. 本课授权边界：文件只读、不联网、不发布、不写原始目录；交付物只能写入指定的输出目录。
4. 纯对话那一轮不允许上传文件，也不允许把带工具那轮的结果复制过去，否则对比无效。
5. 「能跑通」不等于「可交付」：产物中每个数字必须能回到 CSV 行号或分组小计。

## 三、详细操作步骤（合计 80 分钟）

**步骤 1｜8 分钟｜冻结材料、写授权边界**

新建工作区上传 8 个文件，输出目录 L08-个人-智能体实验-v1。发通用准备提示词，明确授权：文件只读、不联网、不发布、不写原始目录，产物只落输出目录。让 WorkBuddy 复述授权清单，并先给「将调用哪些工具」的一句话说明（承接第 12 课 Harness 开销概念）。

**步骤 2｜16 分钟｜第一轮：纯对话（对照基线）**

新开会话 A，不上传任何文件，只把 task_brief.txt 的文字需求贴进去，让它给一份月度小结。原样保存回答。检查：它给出的数字是真实的还是编造的？能否指回具体文件行？把「不可核验」的地方逐条列进 L8-对比实验表.csv。这一轮的价值恰恰在于证明「没有工具做不到什么」。

**步骤 3｜16 分钟｜第二轮：带工具的端到端任务**

新开会话 B，上传 borrow_records_march.csv 与 materials_catalog.csv，按 task_brief.txt 下需求：先列出将生成/修改的文件清单并等你确认，再执行「读文件 → 按物资汇总 → 生成小结 md → 生成汇总 csv → 输出轨迹说明」。逐次确认工具调用；若出现写原始目录或联网请求，拒绝并记录。保存产物与可见的工具调用记录。

**步骤 4｜16 分钟｜拆五阶段轨迹并定位越界**

用 agent_trace.csv 的 10 步模拟轨迹（若会话 B 有真实轨迹则并列对照），填 L8-五阶段拆解表.csv：每阶段写对应步号、输入、工具动作、观察结果、是否合规。重点定位第 07 步的越界写入尝试：它想做什么、为什么该拒绝、应在哪个检查点被拦下、拒绝后如何继续。再用一句话说明「为什么能跑通不等于可交付」。

**步骤 5｜14 分钟｜画最小权限矩阵 + 对比表**

填 L8-权限矩阵.csv：对纯对话 / 只读连接 / 写入 / 发布 / 联网五类能力，逐格写「需要 / 不需要 / 本课未授权」并给理由。补全 L8-对比实验表.csv 的四个维度（产物可核验性、数字来源、耗时、越界风险）。让 WorkBuddy 基于你填的表生成一段 150 字结论，你再核对有没有把「模拟」写成「真实」。

**步骤 6｜10 分钟｜独立审校与归档**

新开审校会话，只给轨迹、权限矩阵与验收表，让它独立指出「第几步越界、应如何处理、哪一项权限被多给了」。与你的结论比对。归档两轮原始回答、产物、两张表、审校记录，填 L8-验收表.csv 10 项，并写一句衔接第 9 课的话（把这次跑通的步骤固化成可复用流程）。

> 步骤分钟合计：**80 分钟**（与任务时长一致）。

## 五、可复制提示词

**通用准备提示词**

```text
你是我的课堂 AI 项目助理。我将独立完成本课任务，请只根据我上传的本课任务单和配套资料工作。先输出目标、输入文件及版本、限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单，并用一句话说明本轮会加载哪些工具。此轮只做计划，不写文件、不联网、不发布。
```

**带工具端到端任务**

```text
目标：把 3 月借用记录整理成月度小结。范围：只读我上传的两个 CSV，不访问其他目录、不联网、不发布。口径：按物资汇总借出次数，归还状态单独统计。交付：小结 md + 汇总 csv + 一份轨迹说明，全部写入指定输出目录。先列出将生成/修改的文件清单等我确认，再执行；每个数字标明来自哪个文件与分组。遇到需要写原始目录的动作，先停下来问我，不要自行决定。
```

**轨迹拆解**

```text
只读 agent_trace.csv，把 10 步归入五个阶段（感知与读材料 / 规划 / 调用工具 / 观察与校验 / 交付与迭代），逐阶段写输入、工具动作、观察结果、是否合规。单独指出哪一步是越界写入尝试、为什么必须拒绝、应在哪个检查点拦截、拒绝后如何继续。不要把「执行成功」当作「合规」。
```

**独立审校（新会话）**

```text
你是独立审校员，只拿到模拟轨迹、权限矩阵和验收表。请独立回答：越界发生在第几步、正确处置是什么、五项能力里哪一项被多给了授权、纯对话那轮最根本的缺陷是什么。每项写依据步号或矩阵行，不确定写「需核验」。
```

## 通用执行规程（16 次课通用，单人独立完成）

1. **独立工作区**：每位学生在 WorkBuddy 中新建本课工作区，一次上传本包内全部素材；提示中声明「本课只能使用这些材料」。输出目录按 `L课次-个人-成果名-v版本` 命名。
2. **先计划、后动手**：先发「通用准备提示词」，要求 WorkBuddy 只输出目标理解、输入文件与版本、必须遵守的限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单；**此轮不写文件、不联网、不连接服务、不发布**。你本人逐项确认计划后，再让它一次完成一个工作包。
3. **独立复核**：需要第二视角时，在同一账号下**新开独立会话**扮演审校员，只提供原始材料与验收规则，**不把前一会话的结论透露给它**。同一会话既执行又自证，判为无效。
4. **逐条验收**：用文件字段、算式、测试输出、可见运行页面或独立审查会话作证。**WorkBuddy 说「已完成」不等于通过**；每步保留输入、产物/工具结果、检查结果与下一步。
5. **可观察留证**：保留可见的提示词、工具结果、文件差异、测试与运行结果；不要求、也不保存模型隐式思维链。
6. **安全边界**：练习包内全部为虚构数据与演示身份。不得上传真实学号、手机号、身份证、账号口令或正式密钥。若 WorkBuddy 请求改动超出任务范围、接触个人数据、访问未授权路径、调用外部服务或公开发布，**立即暂停并由你本人确认**；无授权则采用任务单中的「模拟替代」，并显式标注「模拟 / 未启用 / 未上线」，不得把文字草案说成已连接、已触发或已上线。
7. **错误处理**：保留错误版本与可观察记录，另存 `v0-failed`，不覆盖固定输入与测试预期；先找第一次偏离验收要求的位置，再修正、重跑、留下前后对比证据。
8. **提交**：按本任务单「提交清单」逐项勾选，未通过项、模拟项和未知项都要显式写明。成果物命名带课次、个人标识与版本号。

> 评分：每课评价要点合计 100 分。步骤分钟数相加等于本课任务时长；建议按分钟推进，最后留 8—10 分钟做独立复核与归档。
