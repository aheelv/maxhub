# 第 1 次课｜WorkBuddy 功能覆盖清单

> 工具全景与个人红线 · 70 分钟 · 单人独立完成

本题刻意引导使用工作台的多项能力。**若某项功能在当前课堂版本未开通，请按任务单的「模拟替代」处理并显式标注「模拟 / 未启用」，不得写成已真实使用。**

| WorkBuddy 功能 | 本课用法 | 应留证据 | 完成情况 |
| --- | --- | --- | --- |
| 文件上传与读取 | 一次上传 7 个素材，限定「只用这些材料」 | 准备提示词与回复截图 | ☐ |
| 结构化表格输出 | 生成四层全景表与五维对比表 | 导出的 csv / md 表 | ☐ |
| 多会话独立审校 | 新会话盲审三项结论，不投喂前一会话答案 | 两个会话的提示词对比 | ☐ |
| 文档与资料库归档 | 把复盘卡与红线清单存入本课工作区，形成个人经验库第一条 | 工作区文件清单截图 | ☐ |
| 对话与追问 | 三轮同题对比、逐项打分理由 | 三轮原始回答原文 | ☐ |

共 **5 项**功能。逐项勾选并留存证据；勾选项数计入过程评价。

> 说明：WorkBuddy 为本课程核心工具。涉及代码仓库、预设对照或运行时观察时，可结合 Trae 与 DeepSeek Harness 做对照实验，但对照不是完成本题的必需条件。
