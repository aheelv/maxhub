## 一、任务说明

### 主题对应

对应课件《AI + 表格：智能表格、公式生成与数据清洗》：自然语言生成公式后必须复核引用范围与边界、五类脏数据（重复 / 缺失 / 格式不一 / 单位混用 / 异常值）要先写规则再动手、「原始表只读 + 结果另存 + 清洗留痕」、随机抽样 20 行验证没有引入新错误。

### 题目背景（背景资料）

校园「二手教材寄售」平台导出了 3 月订单表，运营同学想直接拿它算佣金，但表里混着重复订单、金额写成「58元」和「58」两种、日期有 3 种格式、门店名有简称与全称、还有两条负数金额的异常记录。更麻烦的是，往届同学让 AI「清洗一下」，AI 顺手把负数当成正数补进了合计，佣金算多了一截。你这轮要独立用 WorkBuddy 按「先写规则、再执行、后抽样」的顺序完成一次可追溯清洗：先生成并人工复核三个公式，再按五条规则清洗，最后随机抽 20 行验证清洗没引入新错误。

### 本课大题

**由你一人用 WorkBuddy 完成《订单表清洗与公式复核报告》：三个可复核算式、一份干净表、一张清洗留痕表、一次 20 行抽样复核，以及清洗前后合计金额的对账说明。**

### 独立完成规则

全程单人完成。原始表 orders_raw.csv 必须只读、不得覆盖；抽样复核由你本人在结果表上随机取行，不能让生成清洗结果的同一个会话既清洗又自证。

## 二、所需素材

本包内全部文件均为课堂虚构材料，解压后一次性上传到 WorkBuddy 本课工作区：

| 文件 | 用途说明 |
| --- | --- |
| `orders_raw.csv` | 60 行虚构订单，含 4 条重复订单号、3 个空值、2 条负数异常、多种金额/日期/门店格式 |
| `clean_rules.txt` | 五条必须先写清的清洗规则与优先级 |
| `L5-公式复核表.csv` | 三个公式模板：公式文本 / 引用范围 / 边界条件 / 手算校验 |
| `L5-清洗留痕.csv` | 模板：行号 / 问题类型 / 依据规则 / 执行动作 / 前后值 |
| `L5-抽样复核.csv` | 20 行抽样表：行号 / 结果值 / 原始值 / 是否一致 |
| `L5-对账表.csv` | 清洗前后行数与金额合计对照模板 |
| `L5-验收表.csv` | 10 项验收项与通过标准 |

另附 `教师核验卡.txt`（**建议完成后再看**）与 `使用说明.md`（16 课通用规程）。

### 固定核验结果（自检用）

1. orders_raw.csv 共 60 行；重复订单号 4 条，空值 3 个，负数异常 2 条。
2. 按 clean_rules.txt 执行后应为 56 行（60 - 4 条重复）；2 条负数记录标「待确认」保留但排除出合计，不删除、不取绝对值。
3. 金额字段中「58元」「58.00」「 58 」应统一为数值 58；日期统一为 YYYY-MM-DD；门店简称统一为全称。
4. 清洗前后含异常合计与有效合计必须分别对账；只有「有效合计」可用于算佣金。
5. 抽样 20 行中若出现任一「结果值与原始值不一致且留痕表无记录」，判清洗引入新错误，需回滚重跑。

## 三、详细操作步骤（合计 80 分钟）

**步骤 1｜8 分钟｜冻结原始表并写通用准备**

新建工作区上传 7 个文件，输出目录 L05-个人-订单清洗-v1。发通用准备提示词，明确三条硬约束：orders_raw.csv 只读、结果另存 orders_clean.csv、任何删除/改写都要在留痕表有行号记录。让 WorkBuddy 复述这三条，并先给计划不写文件。

**步骤 2｜16 分钟｜三个公式：AI 生成，你来验**

让 WorkBuddy 用自然语言生成三个公式：①有效合计（排除负数与空值）②按门店分组小计 ③佣金 = 有效合计 × 费率。对每个公式，你必须在 L5-公式复核表.csv 写清引用范围（起止行）、边界条件（空值/文本/负数如何处理）、并手算一个 3 行小样本校验。特别注意引用范围是否漏掉最后一行——这是 AI 写公式最常见的错。

**步骤 3｜18 分钟｜先写规则、再清洗五类脏数据**

先逐条确认 clean_rules.txt 的五条规则与优先级，再让 WorkBuddy 按规则执行：重复订单号保留最早一条、金额统一为数值、日期统一格式、门店名归一、负数标「待确认」并排除出有效合计。要求它同时输出 L5-清洗留痕.csv 风格的中间表（行号 / 问题类型 / 依据规则 / 前后值），并另存 orders_clean.csv。你核对留痕行数是否等于发现的问题数；不相等就说明有「悄悄改了没记录」的动作。

**步骤 4｜16 分钟｜20 行随机抽样：新会话盲查**

新开一个 WorkBuddy 会话，只给它 orders_raw.csv、orders_clean.csv 和清洗规则，不给清洗结论。请它随机抽取 20 行，逐行对照原始值判断「改动是否有规则依据、是否被留痕表记录」，输出 L5-抽样复核.csv。你本人再核对其中至少 5 行。任何一处不一致且无留痕，立即回滚（不用覆盖，另存 v0-failed 后重跑并说明原因）。

**步骤 5｜14 分钟｜对账：把两个合计说清楚**

填写 L5-对账表.csv：原始 60 行含异常合计、清洗后 56 行有效合计、两者差额及构成（4 条重复 + 2 条负数 + 格式统一带来的 0 差额）。让 WorkBuddy 用一句话说明「为什么不能用含异常合计算佣金」。再把三个公式套到有效合计上算出佣金，保留算式。

**步骤 6｜8 分钟｜归档与验收**

把原始表、干净表、留痕、抽样、对账、公式复核表一起归档；新开审校会话按 L5-验收表.csv 检查 10 项（原始表未被覆盖、行数、去重、负数处理、格式、留痕齐、抽样一致、对账可算、公式边界、文件命名），输出一张通过/不通过清单。

> 步骤分钟合计：**80 分钟**（与任务时长一致）。

## 通用执行规程（16 次课通用，单人独立完成）

1. **独立工作区**：每位学生在 WorkBuddy 中新建本课工作区，一次上传本包内全部素材；提示中声明「本课只能使用这些材料」。输出目录按 `L课次-个人-成果名-v版本` 命名。
2. **先计划、后动手**：先发「通用准备提示词」，要求 WorkBuddy 只输出目标理解、输入文件与版本、必须遵守的限制、按分钟的操作计划、逐项验收方法、将生成或修改的文件清单；**此轮不写文件、不联网、不连接服务、不发布**。你本人逐项确认计划后，再让它一次完成一个工作包。
3. **独立复核**：需要第二视角时，在同一账号下**新开独立会话**扮演审校员，只提供原始材料与验收规则，**不把前一会话的结论透露给它**。同一会话既执行又自证，判为无效。
4. **逐条验收**：用文件字段、算式、测试输出、可见运行页面或独立审查会话作证。**WorkBuddy 说「已完成」不等于通过**；每步保留输入、产物/工具结果、检查结果与下一步。
5. **可观察留证**：保留可见的提示词、工具结果、文件差异、测试与运行结果；不要求、也不保存模型隐式思维链。
6. **安全边界**：练习包内全部为虚构数据与演示身份。不得上传真实学号、手机号、身份证、账号口令或正式密钥。若 WorkBuddy 请求改动超出任务范围、接触个人数据、访问未授权路径、调用外部服务或公开发布，**立即暂停并由你本人确认**；无授权则采用任务单中的「模拟替代」，并显式标注「模拟 / 未启用 / 未上线」，不得把文字草案说成已连接、已触发或已上线。
7. **错误处理**：保留错误版本与可观察记录，另存 `v0-failed`，不覆盖固定输入与测试预期；先找第一次偏离验收要求的位置，再修正、重跑、留下前后对比证据。
8. **提交**：按本任务单「提交清单」逐项勾选，未通过项、模拟项和未知项都要显式写明。成果物命名带课次、个人标识与版本号。

> 评分：每课评价要点合计 100 分。步骤分钟数相加等于本课任务时长；建议按分钟推进，最后留 8—10 分钟做独立复核与归档。
